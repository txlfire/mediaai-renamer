# CD2 任务绑定固定连接上下文，首版保留全局保护

状态：accepted。2026-10-23用户确认D1至D8；本决定只确认需求和安全边界，不表示多连接已实现、库迁移或云请求获准。

采用多CD2连接、每连接多个目录配置及任务固定来源；连接使用权、显式目录白名单与原动作权限取交集，不增加角色。个人默认选择只影响预填。保存多套配置后覆盖全局active配置的方案被排除，因为它不能保证worker、历史UUID、恢复及反向计划仍指向原目标。

首版仍全局保守串行，未知保护与冷却不因切换来源解除；暂不按连接地址拆并发池。不同地址可能访问同一115账号，缺少来源证据时并行会扩大风险。旧历史不可靠归属时保留原所有者只读，不因迁成默认连接而重新获得执行资格。显式诊断分层显示TLS、Token和精确版本，计入原预算，不自动登录或列目录。

同一连接内拒绝相等或祖孙重叠的批准根；不同连接允许配置同一个115目录，保留家庭/公司同目录场景。跨连接访问范围按已有授权的并集理解，已知别名提示风险，未知别名不承诺自动识别；另一目录配置未授权不是对已授权父根的文件系统拒绝规则。在批准根内选择更深目录盘点仍允许，不要求新增重叠配置。

代价：多连接首版提升配置与任务可用性，但一个未知操作仍可能阻塞其他连接；不能宣称跨别名路径变化只影响所选连接。未来放松保护需独立证明实例/云账号/来源关系与普通文件任务映射，不能通过删除全局唯一索引直接提速。
