# CD2 / 115 网页配置

类型：操作手册。适用于开发源码 schema55，尚未发布；既往 schema54 的云端验收记录不等于本次配置迁移已在 NAS 部署。

## 1. 配置入口

操作：使用拥有 `settings:write` 权限的用户登录，进入“系统设置 → 目录整理（CD2 / 115）”。

预期：显示数据库中当前配置与修订号。配置尚未维护时地址、批准根为空，网页盘点、目录改名、文件隔离三个开关均关闭。配置页面不存储 CD2 账号、密码、临时 Token 或私钥。

常见错误：没有权限时不可维护；读取失败时保存不可用，先核对服务和权限，再点击“重新加载”。不要通过编辑 SQLite 或旧 TOML 绕过保护。

## 2. 填写与保存

| 字段 | 填写要求 |
| --- | --- |
| CD2 HTTPS 地址 | 固定 HTTPS 入口，例如 `https://cd2.example.invalid:19799`；不含账号、密码、路径或查询参数 |
| 批准媒体根目录 | 云盘下的明确媒体目录，如 `/cloud/movies`，不使用 `/` 或整云盘根 |
| 公开 CA 证书 | 私有证书粘贴公开 PEM 证书链，最多16KiB；留空使用系统信任，不粘贴私钥 |
| 最小请求间隔 | 2至300秒，等待计入动作截止时间；大间隔可能使写计划无法在预算内受理 |
| 失败冷却 | 60至86400秒；保存不会清除已有冷却或手动暂停 |
| 映射修订标识 | 最多64个字母、数字、下划线、点或短横线；重绑账号/改变挂载后更新；启用写功能前必须填写 |
| 隔离目录名称 | 安全单层名称，默认 `_MediaAI_Quarantine`；必须事先由用户创建并被盘点，产品不会自动创建 |

操作：仅开启当前获准功能，点击“保存配置”，核对旧观察及相关计划失效提示后确认。

预期：配置与审计同一事务保存，修订递增，无需重启应用；保存本身不连接云盘、不盘点、不改名或移动。重复保存完全相同配置不递增修订。公开 CA 摘要是规范化 PEM 链的 SHA256，不是单张证书 DER 指纹。

常见错误：出现“配置已被其他页面修改”时重新加载并核对，不能盲目重复保存。公开 CA 校验仅证明内容格式，不证明目标可达、主机名匹配或版本支持。

更改开关、间隔等配置同样使旧观察/计划失效，原记录仍可查看；首次只盘点、之后才开启写功能时，需要重新盘点选定小范围再生成计划。产品不自动发起这次盘点，勿因此扩大为整库扫描。

## 3. 开始盘点

操作：应用本身也通过可信 HTTPS 访问；在设置中明确开启“启用网页本层盘点”。然后进入左侧“目录整理 → 新建盘点”，填写批准根内的本次目录和 CD2 的短期最小权限 Token，核对预算后确认。

预期：每次仅本层，最多4次应用 RPC、30秒、100条、1MiB元数据；不递归、不读取正文。Token 只在内存交接，不随配置保存。普通 HTTP 可维护本地配置和查看观察，但不能交接 Token 开始云盘点。

常见错误：策略可用不等于连接成功。遇到超时/未知结果保留原请求编号，先核对原任务，不重复提交。大库按电影/电视剧/地区等较小目录逐步处理；超过100条不能把截断观察当成本层完整。

## 4. 任务保护

操作：出现配置保护提示时，先查看原扫描、文件写任务、后台任务及云动作。待启动任务可按其页面取消，运行任务等待正常退出；结果未知的任务须按原核对流程处理。

预期：待启动/运行任务、未回收 worker、未决 RPC、本地/远端文件动作保护存在时拒绝保存；不会因为超过时间、刷新页面、关闭开关或改地址就清除保护。配置改变会推进全实例保守路径世代，使旧扫描、观察和相关计划失效，不自动重扫。

常见错误：不要手工删槽、改数据库状态或另开实例继续请求。目录改名和隔离各自还要求直接执行权限、维护窗口和逐次明确确认；设置开关不授予正式媒体操作权限。

## 5. 旧实例升级

操作：先在旧版本处置待执行任务、确认所有 worker 实际退出、所有未知结果已按原流程核对，再停止旧实例并备份数据库及凭据密钥。升级到 schema55 后进入本页面重新确认配置与开关。

预期：迁移只新增空配置表，保留旧预算、审计和未决保护；不自动读取或导入 `[cloud_drive]`，旧文件不再是配置来源。若升级时仍有保护，设置会继续被锁定，不能通过首次保存绕过。

常见错误：未知状态尚未解决时不要先升级。需要回退时使用升级前匹配的数据库与代码/镜像，不让旧版本直接打开已迁移的库。迁移不会替用户撤销 CD2 Token。
