# 多连接开发版操作说明

类型：操作手册。仅适用于完成离线迁移并经批准切换到本轮开发制品的实例，不适用于已发布v1.4.0的单配置页面。本地验证状态见[MC5记录](../development/cloud-drive/mc5-web-implementation.md)。当前运行库没有自动迁移，保存配置也不会迁移。

## 1. 管理连接和目录

操作：以具备`settings:write`的用户进入“系统设置 → 目录整理（CD2 / 115）”，新增连接，填写名称、HTTPS地址及需要的公开CA。选择“管理目录与授权”，在抽屉中新增目录配置，明确批准根、映射标识和隔离目录名称。

预期：只保存MediaAI数据库；新连接、目录默认禁用，盘点、目录改名和隔离开关默认关闭。批准根与映射不能直接重绑，需要时新建目录配置；同连接内批准根不得相等或祖孙重叠。可以配置公司、家庭两套连接和各自不重叠的媒体目录。

常见错误：地址、公开证书或批准根无效时拒绝保存。不要粘贴私钥、账号密码或临时Token。保存结果未确认时先刷新核对，不重复创建；关闭未保存草稿会要求确认。

同地址轮换 CA 使用「更新证书」。用户原授予的目录范围不变，但之前的诊断及旧任务的执行依据不能沿用。更换地址时新增连接及目录并重新授权；旧连接的任务和目录不会移到新地址。

## 2. 分配直接用户授权

操作：在连接抽屉的“用户授权”选择用户，勾选连接使用权及目录白名单后保存。

预期：连接权、目录白名单和原动作权限同时生效；无角色层。新增目录不自动授权，“勾选当前页”不代表未来目录也授权。翻页保留已勾选ID，保存不会启用云操作。

常见错误：用户具备扫描权限但没有连接/目录授权时，不能通过猜ID使用来源；管理员也需明确授予业务使用范围。跨连接配置同一个115目录不构成隔离屏障，不能把另一项“未授权”当作文件系统拒绝规则。

## 3. 显式诊断

操作：进入“目录整理 → 诊断连接”，明确选择连接、目录和路径；选择TLS或受限Token/版本阶段，读取本地政策并确认后执行所选阶段。

预期：两个阶段独立确认、独立编号；TLS不携带Token，受限Token只在可信HTTPS内存交接。已授权禁用来源可以诊断，归档来源不可选。TLS通过不表示Token、精确双Build或写能力通过，受理202也不是成功结果。

常见错误：未迁移实例显示相应原因，不回退单配置。未知结果保留原编号，只核对原记录；运行中最多20次、间隔1.5秒刷新本地结果，不产生新的CD2请求。关闭不代表远端已停止，Token使用后仍应在CD2撤销。

## 4. 创建盘点与读取历史

操作：选择“新建盘点”，明确连接、目录和批准根内的本次子路径，读取政策、确认仅本层，使用短期受限Token交接。

预期：不默认选择某套连接；切换连接、目录或路径清空旧政策与未提交Token。盘点按固定预算停止，不递归、不读取正文、不自动扩大到整盘。多个连接仍共享全实例保守串行、间隔、冷却、预算和未知保护。

操作：展开目录整理顶部筛选区筛选盘点任务；目录计划、复核记录和隔离记录的弹窗也可按授权连接、目录筛选。

预期：只查询本地历史，不调用云盘、不替换当前打开任务的来源。原名称与当前配置名分别展示，禁用来源的可读历史仍可筛选。清空连接同时清空目录，回到仍有读取权限的全部历史。旧未绑定记录仅只读，不能套用当前连接执行。

常见错误：来源绑定缺失或筛选响应不符时拒绝展示，不自动放宽筛选。页面隐藏、权限或会话变化后，重新打开页面/弹窗核对；不沿用旧筛选项作为授权证明。

## 5. 原请求保护核对

操作：点击顶部“保护核对”，输入本人原请求UUID，读取最小摘要；需要时确认“停止后续”。诊断弹窗也可带原编号打开该入口。

预期：已登录原所有者即使失去扫描或动作权限，仍可读取脱敏保护摘要、记录停止意图；不显示目录、文件或日志。停止不证明远端已停止，不释放未知、请求槽、路径保护或预算。

操作：管理员在设置“保护管理”或保护弹窗的“管理保护列表”查看分页进程元数据。仅对已有占用的只读任务，双重确认后核对原修订及退出证据。

预期：服务端仍需验证原主机和父子进程退出；最多归还本机进程槽。目录改名、隔离及其位置核对不使用通用进程回收。结果未确认必须先重读，不能直接重复提交。

## 6. 受控改名与隔离

操作：按原盘点/复核创建固定计划，再经维护窗口、单写者、预算及Token确认执行。隔离后的反向恢复通过新的反向计划完成，不重放原动作。

预期：政策、回执、执行及只读观察均核对原连接、目录、路径和上下文；不使用新任务筛选项覆盖原来源。未知结果只能按原编号查询并另行批准只读核对，原未知事实保留。目标冲突不得覆盖，不读取正文或永久删除。

常见错误：原计划失效、授权/来源修订变化、全局保护占用或精确版本未验证时不执行。本文不构成真实云验收或正式媒体写入授权。
