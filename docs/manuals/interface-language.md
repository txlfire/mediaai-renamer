# 界面语言

类型：操作手册。简体中文和英语切换已在当前开发版启用；不属于已发布的v1.4.0。

1. 在登录页选择“中文”或“English”；登录后使用侧栏底部的同一语言选择器。侧栏收起时先展开。
2. 切换立即生效，不刷新页面。界面保留当前路由、未保存的表单内容、分页和已选对象。已经弹出的提示有时仍采用打开时的语言，关闭后重新打开即可看到新文案。
3. 同一浏览器和访问地址下，刷新后保留选择。没有保存偏好时，优先匹配浏览器语言；未匹配时使用简体中文。浏览器禁止写本地存储时，本次切换仍有效，下次打开可能恢复浏览器默认语言。

界面语言不改变媒体标题、文件名、目录、命名规则、TMDB语言偏好或已保存的日志、审计和导出。第三方、用户输入及历史记录中的原文不自动翻译。
