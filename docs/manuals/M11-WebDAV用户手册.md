# M11 WebDAV 用户手册

## 1. 新增媒体源

1. 打开“媒体源”。
2. 路径类型选择“WebDAV”。
3. 目标路径填写完整 HTTPS 地址，例如 `https://nas.example.com/dav/movies/`。
4. 无认证服务不填写账号和密钥。
5. Basic 认证填写用户名和密码。
6. Bearer 认证不填写用户名，只在密钥字段填写 Token。
7. 点击测试连接，成功后保存媒体源。

系统不接受 `http://` 地址，也不提供跳过证书校验选项。

## 2. 扫描和预览

WebDAV 媒体源与其他媒体源共用扫描任务。扫描会递归读取文件名、大小、修改时间和 ETag，并按文件扫描配置过滤。

扫描完成后进入“重命名”生成预览。命名模板、元数据匹配、AI 解析、敏感词保护和待处理列表规则与本地文件一致。

## 3. 重命名

执行顺序：

1. 生成预览。
2. 选择条目。
3. 执行 dry-run。
4. 阅读文件数量、目标路径和风险提示。
5. 确认后执行重命名。

WebDAV 重命名使用服务端 MOVE，并禁止覆盖已存在目标。网络中断或服务器拒绝操作时，失败条目会保留记录。

## 4. 回滚

成功的 WebDAV 重命名批次可以创建回滚计划。回滚也先执行 dry-run，确认原目标存在且回滚目标不存在，再执行反向 MOVE。

## 5. 失败恢复

打开“任务治理”，切换到“WebDAV 恢复”：

- 可按媒体源、操作类型和状态筛选。
- 可查看源路径、目标路径、错误和恢复详情。
- 点击恢复前系统会再次检查远端状态。
- 可安全重试时执行 MOVE。
- 远端已完成时只补齐数据库。
- 状态有歧义时停止自动操作，并标记为需要人工处理。

WebDAV 恢复不是任务归档恢复，不会改变普通任务的归档状态。

## 6. 常见问题

**连接失败**

检查网络、DNS、HTTPS 证书信任链和反向代理。

**认证失败**

检查用户名、密码或 Token，并确认账号对目标目录有读取和 MOVE 权限。

**可以浏览但不能重命名**

确认代理放行 MOVE，保留 `Destination` 和 `Overwrite` 请求头，并确认账号有写权限。

**目标文件已存在**

系统禁止覆盖。修改命名模板或目标文件名后重新生成预览。
