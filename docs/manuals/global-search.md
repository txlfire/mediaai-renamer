# 全局搜索

类型：用户操作说明。核对日期：2026-10-30。适用于当前未发布开发版，不是固定 v1.4.0 制品已有功能。

## 搜索

1. 登录后点击页面顶部“全局搜索”。输入2–128个字符，停顿300ms或点击“搜索”。中文输入法组词期间不发请求。
2. 名称、文件名使用包含匹配；`%`、`_`按字面匹配。`#1`按各分类记录的编号精确匹配；后台任务也可搜索原请求UUID。ASCII大小写不敏感，不承诺非ASCII大小写折叠。
3. “全部”每类最多10条，按记录编号倒序，不是相关度排序。点击“查看此类更多结果”进入单类首页，再用“下一页”读取更早编号。“返回首页”回到该类首批；没有全库总数。
4. 点击条目，读取该稳定编号的当前详情。“打开所属列表”进入该源或扫描任务的原列表；列表不保证该条目位于第一页。精确记录先在搜索详情中核对。“查看后台任务”在当前页打开既有后台任务抽屉，并保留当前业务路由参数。
5. 右上角关闭、底部关闭或ESC关闭；隐藏页面、会话或权限变化也清理查询与结果。搜索词和最近搜索不持久保存，不进入导航URL。

## 检索范围

| 分类 | 匹配字段 | 读取边界 |
| --- | --- | --- |
| 媒体源 | 名称、协议 | 沿用既有已登录读取权限，不查询连接密码、账号和配置正文 |
| 扫描任务 | 编号、媒体源名称、状态 | 沿用既有已登录读取权限 |
| 媒体文件 | 已入库文件名 | 不查询文件系统或正文；来源为已落库扫描记录 |
| 重命名预览 | 解析标题、建议名、编辑名、原文件名 | 仅返回白名单摘要；不生成预览、不匹配、不执行改名 |
| 后台任务 | 编号、请求UUID、类型、状态 | 仅本人创建且当前保留该任务动作权限；task:manage不扩大搜索范围 |

CD2盘点/目录计划/隔离历史、重命名执行与回滚记录、日志全文、媒体正文及外部网盘搜索不在本批。CD2原页面的历史筛选和按原请求核对入口继续使用，不被全局搜索代替。

## 常见情况

- 无结果：当前本地库中没有匹配项，或后台任务不属于本人/动作权限已撤销；不会自动补扫。
- 查询超时或暂不可用：可能达到SQLite预算或搜索并发槽已满。选单类、使用更具体的词或`#编号`，再手动查询。系统不会返回半截结果冒充完成，也不会自动重试。
- 记录已删除、已清理或无权读取：刷新搜索；详情和跳转前都会重读原编号，不回退到其他记录。
- 多页搜索不是跨请求冻结快照，期间增删改可能改变匹配；游标按稳定ID向前，新增记录需返回首页查看。

容量证据与限制见[搜索实现与验收](../development/global-search/implementation.md)。
