# CD2 本层盘点与观察维护

类型：操作手册。适用于未发布schema55开发源码，不属于稳定v1.3.0。本文不授权任何云请求或文件操作。

## 新建本层盘点

操作：管理员按[配置手册](cd2-settings.md)维护数据库设置并明确开启网页盘点。通过可信HTTPS打开左侧“目录整理 → 新建盘点”，选定批准根内的小分类目录，输入精确根、仅列目录权限的短期Token后逐次确认。

预期：本次最多4次应用RPC、30秒、100条、1MiB，仅本层。大库按电影/地区/剧集等小范围处理；本层完整不等于子树完整或数据持续新鲜。遇预算截断不能改称完整，不自动递归或重新扫描。

常见错误：目录条目过多、TLS/Token或未知保护失败时先核对原因与原请求；不能切回挂载盘符的普通扫描绕过限制。文件夹本身改名需要其父层完整观察，进入子文件夹不能替代父层证据。

## 保留例外

操作：打开条目详情，选择“本次保留”并确认；需取消时在同一条目选择“取消本次保留”。

预期：只绑定当前盘点条目，不跨重新盘点自动套用；保留后不把该条目交给外部服务或后续改名/隔离计划。改变保留状态会修订本地观察，使依赖旧修订的计划失效。

常见错误：旧页面修订不符时刷新重新核对，不自动合并覆盖。人工复核记录中的“保留”是该记录结论，与条目的“本次保留”不是同一个操作。

## 导出本页

操作：完成当前页加载、刷新应用待处理筛选后点击“导出本页”。

预期：只导出当前视图已有行，包含观察及建议，不是整任务、所有分页或后台云扫描；没有执行脚本或云操作授权。CSV可能含私人文件名/路径，不公开上传。

常见错误：页面有未应用改动、观察已清理或没有数据时导出不可用。不要用导出数量估计全库文件数。

## 清理观察

操作：任务已经结束、worker实际回收且没有未决RPC时，点击“清理观察”，确认只删除本地观察。分批清理中断后可点“继续清理”。暂停任务先取消，再核对退出和未决状态。

预期：删除该任务观察及本次保留例外，无法恢复这些观察；批准范围、已用预算、请求标识和审计仍保留，固定复核/计划证据不随观察级联删除。旧来源显示失效，不删除云文件、不自动补扫，也不进行在线VACUUM。

常见错误：按钮置灰说明条件未满足，不能手工删租约/PID来解锁。普通运行日志另按系统日志策略清理，日志已清理不能等同安全账本或观察已清理。

若服务在领取盘点后、绑定子进程PID前退出，任务可能保留槽而PID为空。本机维护者仍须通过[接入检查中的恢复CLI](../deployment/cd2-readonly-preflight.md#6-正式升级前核对与回退)核对原任务，确认相关客户端已停止及远端静止。系统要求原owner属于本机且确认退出、绑定未变化，未绑定时没有该会话未决RPC或reading目录，才允许归还任务槽；不会因PID为空直接放行，也不会删除未知租约或自动重新扫描。核对失败保留现场，不直接修改数据库。
