# 修改服务端口

本页适用于包含端口设置的开发版。已公开的 v1.4.1 不包含此页面。

1. 使用有系统设置权限的本地账号，进入「系统设置 → 通用设置」顶部的「服务端口」。显示「本机开发 · 可编辑」时可填端口；若提示未报告本机开发模式，先按下文用项目启动命令恢复该模式。
2. 填写两个不同的 TCP 端口（1024–65535），点击「保存端口」。首次可以直接保存当前端口；只有待生效端口与当前监听不同，才显示「待重启生效」。保存不会中断网页或后台进程。
3. 确认可以手动重启本地开发服务后，运行 `npm.cmd run dev:windows -- restart`（Linux：`npm run dev:linux -- restart`）。使用新前端地址访问；Vite 的 API 代理随新后端端口更新。
4. 若启动时端口已被占用或被 Windows 保留，不结束其他进程。释放该端口，或者用[开发指南的临时覆盖](../development/development-guide.md#windows保留端口)恢复访问，再在设置页更改待生效端口。

Docker 或反代部署在此区只显示当前访问地址。请按原部署文档调整 Docker 端口映射或反代入口；应用不会改宿主映射、证书或防火墙。

从旧脚本启动的开发实例升级时，先通过新版开发启动器按原端口重启一次，页面才会识别本地开发模式。以当前本机为例：`npm.cmd run dev:windows -- restart -FrontendPort 6061 -BackendPort 9070`。此命令会短暂停止本地服务；保存应用设置以后，下次启动不必再附端口。
