# CD2 广告人工复核

文档类型：操作手册。适用于未发布开发源码schema55，不属于已发布v1.3.0能力。

## 新建复核

1. 进入目录整理，选择已完整结束的盘点任务，刷新当前页。
2. 点击“广告人工复核”，明确勾选本页普通文件。默认不选文件，目录不能选入。
3. 逐项选择保留、待确认、建议隔离或建议删除。后两种须填写人工理由；没有规则线索或身份的文件不能保存为这些建议。保护文件和当前保留例外只能保留。
4. 勾选仅保存本地建议的确认，点击“保存复核清单”。

预期：生成固定清单，不下载正文、不调用AI、不隔离、不删除。已保存清单不可编辑，需要更改时新建复核。复核中的“保留”只记录本清单结论，不自动跨任务添加长期例外；已有当前条目保留设置继续独立维护。

常见错误：任务未结束、观察清理、修订或路径水位变化时须先刷新或重新盘点；不能用旧观察继续确认。文件大小或扩展名不能单独决定广告。

## 查询和导出

- 保存响应不明确：保留地址栏中的 `ad_review_request_id`，点击“查询原复核”；不要重复保存新请求。
- 查看旧记录：点击“复核记录”，分页找到本人记录，点击详情图标；切换原请求时会提示。
- 点击“导出复核清单”：下载CSV，包含固定范围、证据、结论、理由及查询时来源状态。它不是执行脚本，不能导入触发云端动作。

预期：来源已清理、规则或路径已变化时仍可查看历史证据，并显示历史提示。来源修订一致只代表本地查询时一致，不保证云端对象仍在原位置。

CSV可能包含私人路径和文件名，勿公开上传。当前限制为每次100文件/512KiB、全库200记录/20MiB逻辑JSON；达到上限停止新增，不自动删除旧清单或审计，也不自动压缩SQLite文件。

## 未开放能力

本页面保存复核本身不执行云动作。当前复核中可以明确勾选1至5个“建议隔离”文件，进入独立固定计划；执行仍需独立权限、默认关闭开关、HTTPS临时Token及维护窗口确认，见[隔离与反向恢复](cd2-quarantine.md)。

正文取样、真实删除、自动清空隔离区或回收站未开放。不要将“建议删除（未执行）”理解为已经判定可安全删除。能力与实机证据分开记录，见[能力核对](../development/cloud-drive/c3-capability-assessment.md)。
