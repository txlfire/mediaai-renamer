# M11 WebDAV 设计手册

> 历史阶段资料：保留当时的设计、操作或验收语境，不作为当前版本的操作依据。现行资料见[文档索引](../README.md)，已交付能力与剩余边界见[项目状态](../development/project-status.md)。

## 1. 目标

WebDAV 作为远程媒体源接入现有扫描、命名预览、安全重命名、回滚和任务治理流程。远程 URL 不伪装为本地路径，所有操作通过共享协议接口执行。

## 2. 能力边界

| 能力 | 实现 |
| --- | --- |
| 协议 | 仅 HTTPS WebDAV |
| 认证 | 无认证、Basic、Bearer |
| 浏览 | `PROPFIND Depth: 1` |
| 扫描 | 递归 PROPFIND，读取大小、修改时间、ETag |
| 重命名 | 仅端点条件 MOVE 能力已验证时，发送 `If-Match` 与 `Overwrite: F` |
| 回滚 | 仅端点条件 MOVE 能力已验证时，执行目标到源的反向 `MOVE` |
| 恢复 | 安全重试、数据库对账、人工处理 |
| 不支持 | HTTP、Digest、TLS 绕过、目标覆盖、跨站点移动 |

## 3. 数据与调用链

```text
媒体源配置
  -> 版本化密文保存凭据
  -> SharedPathContext
  -> WebDavProtocol
  -> PROPFIND / OPTIONS / MOVE
```

扫描结果中的 WebDAV 文件使用完整 HTTPS URL 作为路径。ETag 写入扫描指纹，继续复用现有增量扫描和命名预览数据结构。

## 4. 写操作

1. 生成命名预览。
2. dry-run 检查源存在、目标不存在。
3. 用户确认。
4. 获取 `media-source:{id}:write` 数据库租约锁。
5. 创建带幂等键的 `remote_operation_items` 记录。
6. 发送 `MOVE`，并设置 `Destination` 和 `Overwrite: F`。
7. 更新媒体文件、预览、批次和远程操作状态。
8. 释放租约锁。

发送 MOVE 前必须同时满足：媒体源端点能力快照为 `verified`，且源文件具有强 ETag。缺少任一条件时在传输前拒绝。返回 `201` 才是明确成功；`204` 或其他异常 2xx 表示请求已发出但结果不明确，远程操作进入人工核查且禁止自动重放。

回滚使用同一流程执行反向 MOVE。任何单条失败都会留下远程操作记录，不会静默成功。媒体源路径、用户名或密钥变化后，旧能力快照立即失效。

### 4.1 条件 MOVE 能力验证

能力验证只针对已保存的 WebDAV 媒体源，由具备 `source:write` 权限的用户显式发起。验证期间持有 `media-source:{id}:write` 租约，避免与真实重命名、回滚或媒体源配置修改并发。

验证器在媒体源根目录创建随机 `.mediaai-capability-*` 隔离目录，并依次检查：

1. 错误强 ETag 的 MOVE 必须返回 `412`，源文件不变且目标不存在。
2. 正确强 ETag 的 MOVE 必须返回 `201`，源文件消失且目标文件身份可读取。
3. 目标已存在且 `Overwrite: F` 时必须返回 `412`，源文件和目标文件均不变。

验证结束必须删除隔离目录，并再次 `PROPFIND` 确认返回 `404`。三项语义和清理均通过时记录 `verified`；服务端明确不满足条件写语义时记录 `unsupported`；网络异常、响应缺失、租约失效或清理失败时记录 `unknown`。能力快照与审计事件在同一数据库事务保存，审计失败时不得留下 `verified`。快照绑定规范化端点与凭据版本，路径、账号或密钥变化后自动失效。

## 5. 恢复状态机

- 源存在、目标不存在：可安全重试 MOVE。
- 源不存在、目标存在：远端操作已完成，仅补齐数据库。
- 源和目标都存在，或都不存在：状态有歧义，标记 `recovery_required`。
- 存在有效写锁：拒绝并发恢复。

“WebDAV 恢复”与普通任务归档/恢复是两个独立概念，前端使用独立 Tab 展示。

## 6. 安全约束

- 不提供关闭 TLS 校验的配置。
- 私有 CA 必须加入运行环境信任链。
- 凭据只在后端解密，API 返回脱敏状态。
- MOVE 禁止覆盖目标。
- WebDAV 端点写能力默认 `unknown`；`unknown` 和 `unsupported` 均只允许浏览、扫描和预览。
- 静态协议能力声明不能代替实际端点验证。已确认不执行条件 MOVE 的服务端必须记录为 `unsupported`。
- 远程写操作保留操作者、时间、源、目标、状态和恢复详情。
- 连接成功只代表目录可读，不代表服务端支持安全重命名。

## 7. 测试

容器测试环境使用临时 CA、HTTPS WsgiDAV 和隔离目录，不接触用户文件。GitHub Actions 验证连接、认证失败、浏览、扫描、冲突、MOVE、回滚、恢复、歧义状态和写锁冲突。真实端点验证使用上述随机隔离目录和三项条件写断言，不允许用普通连接成功或静态能力声明替代。
