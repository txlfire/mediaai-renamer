# M11 WebDAV 设计手册

## 1. 目标

WebDAV 作为远程媒体源接入现有扫描、命名预览、安全重命名、回滚和任务治理流程。远程 URL 不伪装为本地路径，所有操作通过共享协议接口执行。

## 2. 能力边界

| 能力 | 实现 |
| --- | --- |
| 协议 | 仅 HTTPS WebDAV |
| 认证 | 无认证、Basic、Bearer |
| 浏览 | `PROPFIND Depth: 1` |
| 扫描 | 递归 PROPFIND，读取大小、修改时间、ETag |
| 重命名 | 服务端 `MOVE`，`Overwrite: F` |
| 回滚 | 目标到源的反向 `MOVE` |
| 恢复 | 安全重试、数据库对账、人工处理 |
| 不支持 | HTTP、Digest、TLS 绕过、目标覆盖、跨站点移动 |

## 3. 数据与调用链

```text
媒体源配置
  -> 版本化密文保存凭据
  -> SharedPathContext
  -> WebDavProtocol
  -> PROPFIND / OPTIONS / MOVE
```

扫描结果中的 WebDAV 文件使用完整 HTTPS URL 作为路径。ETag 写入扫描指纹，继续复用现有增量扫描和命名预览数据结构。

## 4. 写操作

1. 生成命名预览。
2. dry-run 检查源存在、目标不存在。
3. 用户确认。
4. 获取 `media-source:{id}:write` 数据库租约锁。
5. 创建带幂等键的 `remote_operation_items` 记录。
6. 发送 `MOVE`，并设置 `Destination` 和 `Overwrite: F`。
7. 更新媒体文件、预览、批次和远程操作状态。
8. 释放租约锁。

回滚使用同一流程执行反向 MOVE。任何单条失败都会留下远程操作记录，不会静默成功。

## 5. 恢复状态机

- 源存在、目标不存在：可安全重试 MOVE。
- 源不存在、目标存在：远端操作已完成，仅补齐数据库。
- 源和目标都存在，或都不存在：状态有歧义，标记 `recovery_required`。
- 存在有效写锁：拒绝并发恢复。

“WebDAV 恢复”与普通任务归档/恢复是两个独立概念，前端使用独立 Tab 展示。

## 6. 安全约束

- 不提供关闭 TLS 校验的配置。
- 私有 CA 必须加入运行环境信任链。
- 凭据只在后端解密，API 返回脱敏状态。
- MOVE 禁止覆盖目标。
- 远程写操作保留操作者、时间、源、目标、状态和恢复详情。
- 当前只声明目标防覆盖和 ETag 增量识别，不声明通用源版本条件写能力。

## 7. 测试

容器测试环境使用临时 CA、HTTPS WsgiDAV 和隔离目录，不接触用户文件。GitHub Actions 验证连接、认证失败、浏览、扫描、冲突、MOVE、回滚、恢复、歧义状态和写锁冲突。
