# CD2 广告人工复核安全设计

文档类型：安全设计。目标范围确认：2026-10-18。实施与差异见 [C3/C4 计划](../development/cloud-drive/c3-c4-implementation-plan.md)。

## 1. 领域与权限

广告线索、人工复核、云端动作是三个不同对象。广告线索不是广告事实，复核建议不是动作批准；本模块不产生隔离、删除、下载、AI 调用或递归扫描。

`scan:run` 用户只能查看和维护本人的本地观察及复核记录；每次事务重新检查启用状态和直接权限，不引入角色。未来云端取样、隔离、删除须独立设计权限，不借用本权限或 C2 的目录改名权限。

## 2. 输入与证据

用户从当前本地观察明确选择普通文件，最多100个；不默认勾选、不跨页扩大、不接收前端路径、远端ID、证据或规则版本。服务端按文件ID重新读取观察、目录代次和保护规则。

保存要求来源任务完整结束、worker已退出、缓存可用、修订与路径水位一致，端点和批准根仍匹配。任务完整表示批准范围内的观察完成，不表示整分类或115全库已经遍历。

保护规则检查完整路径，包括批准根的上级语义；关联字幕、海报、光盘结构、说明和用户保留例外优先。保护项只可保存为保留。无广告线索、身份缺失的项不能保存为隔离或删除建议；这些结论还须有单行人工理由。普通扩展名、小体积、AD/广告词本身不形成广告证据。

## 3. 固定记录及状态

结论为保留、待确认、建议隔离、建议删除；显示后两种时附“未执行”。每次保存独立固定清单，包含来源任务和修订、路径水位、规则版本、对象及观察代次、证据、结论、人工理由和摘要。

清单保存后不改写，修改结论生成新清单。UUID与请求摘要绑定，相同UUID相同输入返回原记录；不同输入冲突。浏览器提交前保存查询标记，响应丢失只查询原UUID，不自动重发。

`sourceCurrent` 仅描述查询时本地配置、规则、观察修订和路径水位一致，不是云端新鲜度或可执行性证明。缓存清理、保留变化、配置变化、规则变化和路径修订后显示历史状态，固定证据不被观察清理级联删除。

## 4. 事务、容量及保密

复核与关键审计在同一 SQLite 写事务提交，审计失败全部回滚。参数绑定执行 SQL；项目使用 sqlite3，不新增 ORM。普通审计只记录记录标识、项数、逻辑字节和零远端动作，不复制路径、名称、人工理由或凭据。

每清单最多512KiB逻辑JSON，全库最多200条、20MiB逻辑JSON；达到任一上限停止新增，不自动删除人工证据或审计，不触发远端补扫。逻辑上限不代表 SQLite 文件物理上限。本人记录按20条分页，单页上限50，历史列表只读取摘要列，不加载整份JSON。

CSV 是本机用户主动下载的证据报告，包含文件名、路径和理由，不宜公开上传。对所有文本转义引号并防护公式起始字符；历史导出明确标记来源状态和未执行，不提供可导入执行脚本。

## 5. 云能力边界

取样必须另行证明实际上游流量、预读及取消行为，不把本地消费字节当115流量。隔离须验证同云同账号、固定目标、不覆盖/不合并、源身份及未知结果核对；C2同父改名不能替代跨目录移动证据。不能证明时保留复核与导出能力，不自动尝试替代协议。

永久删除、自动清空隔离区、回收站清理、跨云复制后删除和递归删除不在首期范围。

## 6. 独立受控隔离边界

人工复核只提供固定证据。受控隔离是独立领域对象，按用户另行确认的维护窗口、单写者、小批量串行、前后身份核对和未知不重试边界执行；不保证抵御其他客户端并发替换。反向恢复必须生成新计划，不能重放旧请求。

隔离计划和执行使用独立直接权限，执行默认关闭；明确选择的同父普通文件保持原名，目标只允许该父下既有专用目录，不接任意路径。未知保持实例保护，只读位置核对与本地同步分开批准，不因进程退出释放业务保护。具体输入、数据、状态和限制见[受控隔离契约](../development/cloud-drive/c3-quarantine-contract.md)。这不扩大本人工复核模块的权限，也不包含正文取样或永久删除。
