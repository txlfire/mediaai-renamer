# 工作台视觉 v2 设计规范

类型：目标设计。确认依据：用户于2026-10-27接受评估建议并要求修订，随后明确后续页面开发均按新视觉标准执行。本文替代外部视觉语言v2及编码输入语中冲突的执行规则，不证明当前页面已实现。实施顺序和验证状态见[实施计划](../development/ui-refresh/ui-v2-implementation-plan.md)。

## 1. 范围与不变项

面向媒体整理工作台，覆盖扫描任务、扫描结果、媒体源、重命名、目录整理、任务治理、设置、登录及共享弹层。继续使用Vue 3、Element Plus、Pinia和现有路由；不增加UI、动画或在线字体依赖。

保留六主题ID：default、candy、contrast、ocean、forest、amber；显示模式为system/light/dark。forest用于没有保存偏好的新用户；已保存的合法主题及显示模式保持，非法主题仍安全回退default。外观仅为本浏览器偏好，不要求settings:write，也不写入系统数据库。

以下不随外观改变：动作权限、直接用户授权、批量固定集合、单条/勾选/全部范围、危险操作确认、会话代次、原UUID与固定来源、日志清理提示、未知不重试。禁止为了填充稿面新增扫描、正文读取、网络诊断、外部提交或执行能力。

## 2. 颜色与角色

运行时唯一色值来源是frontend/src/styles.css，不新增并行tokens.css。palette提供亮暗基础值，scheme解析语义别名；组件和Element Plus消费角色，不按主题复制组件CSS。页面预览需在自己的palette/scheme作用域解析变量，不能继承当前页面已解析的另一主题。

| 角色 | 职责 |
| --- | --- |
| app-bg / sidebar-bg / panel-bg | 页面、带色导航和内容层次；不靠深边框分割每个区块 |
| panel-soft-bg / input-bg / table-header-bg | 次级区域、输入、表头；不将表头与输入强行共用背景 |
| panel-border / table-divider / input-border | 分区边界、行分隔、必要控件边界；只对实际需要辨识的控件边界使用对应对比度门禁 |
| text-main / text-muted / text-subtle | 主文字、正文标签、辅助信息；不能用辅助色替代禁用、风险或选中语义 |
| table-row-hover-bg / selection-bg | 临时悬停与持久选择分开；选择辅以标记，不仅靠背景深浅 |
| brand-accent / brand-accent-ink | 强调文字、链接和选择等品牌角色；不与业务成功强绑定 |
| button-primary-bg / button-primary-ink / button-primary-hover-bg | 实心主按钮独立前景/背景；深色不得用浅品牌字色直接代替按钮填充 |
| semantic-success / info / warning / danger / neutral | 成功、进行中/信息、需关注、失败/危险、中性；业务状态通过明确映射消费，不减少业务枚举 |
| action-* | 保留既有消费接口，值可归并到稳定动作角色；不按变量条数验收 |

forest浅色的基准取值：page #F2F5F2、sidebar #E4ECDF、panel #FFFFFF、soft #EEF3E9、header #F0F3ED、hover #EDF4E8、selected #D3E3C9、brand #2E6C3F、brand文字强调 #245232；文字三档 #29372B/#53664F/#63725F。卡片边界 #E3E7E0，行分隔 #DDE1DC。输入边界保留可辨识的 #7B8D73，不统一弱化为侧栏边线 #CAD7C4。

forest深色的基准取值：page #171D19、sidebar #1D3025、panel #222B25、soft #26312A、header #344A38、hover #304435、selected #2E4030、品牌强调字 #ACD391；实心主按钮为 #2E6C3F配白字。文字三档 #EEF3E8/#BACBB6/#AAB8A6；必要控件边界使用足够辨识的独立角色，不与装饰分隔线绑定。

其他五主题保留自己的完整亮暗背景、文字、输入、选择、边界和前景角色，不把forest中性色覆盖所有主题。candy侧栏使用粉色系、amber侧栏使用暖中性色；contrast保持加强必要边界的定位。表格行分隔可共享中性值，高对比分区可有例外，不能以“只允许9个变量不同”拒绝必要差异。

成功/信息/警告/失败浅色胶囊采用淡底深字；推荐文字 #0E7A56/#1D4ED8/#8F5A0E/#BC3232与底 #DFF3EA/#E4ECFD/#FBEDD8/#F8E3E3，分别验证实际背景。暗色使用各自暗底亮字，不从浅色透明度直接推导合规。进度填充、文字、弱行底是不同角色。

## 3. 字号、尺寸与图标

- 固定字号阶梯：页面标题20至22px、分区16px、正文/控件14px、说明13px；11至12px只用于非关键辅助信息，不能承载唯一状态、操作或风险说明。不用vw连续缩放字体。
- 中文沿系统无衬线fallback；数字使用tabular-nums。路径/指纹可用系统等宽字体，不强制下载Inter或中文字体。
- 普通工作台控件、表格框和重复项圆角6至8px，胶囊及状态点可圆形；不把整页分区包装为嵌套卡片。
- 常用控件高32至36px；单行表格以44至48px为基线，双行信息按内容至少52至56px。高度是最小约束，不裁切换行文字；密度变量必须带单位。
- 图标沿现有Element Plus库，导航18px、表格动作约16px；不对fill路径全局增加stroke，也不为匹配稿图隐式换库。
- 导航、搜索、装饰图标用中性角色；表格动作保持少量稳定语义色，危险操作红。纯图标动作无边框背景、居中，有可访问名称、tooltip及可见焦点。
- 图标尺寸不等于点击面积。表格动作保持至少24px可操作目标，优先28至32px；紧凑间距另测误点风险。

## 4. 弹性布局与滚动

按实际CSS视口和工作区宽高适配，不按物理分辨率选择固定截图。用户主屏3840×2160、Windows200%、浏览器125%满宽约1536 CSS像素，实际innerWidth/innerHeight须记录。

| 外壳宽度 | 导航和留白 |
| --- | --- |
| 小于900px | 紧凑/折叠导航，内容可重排；主操作可达，低高度允许安全纵向滚动 |
| 900至1399px | 导航默认紧凑，可按用户选择展开；左右padding约16px |
| 1400至1919px | 展开导航约216px，左右padding约24px；1536处必须单独验收 |
| 1920至2559px | 导航约216px，左右padding约28px |
| 2560px及以上 | 导航224至240px，左右padding32至36px，按有效内容而不是硬加空列利用宽度 |

导航手动选择与自动适配分开，不将resize写成永久偏好。侧栏内容超过可用高度时允许自身滚动，设置和退出入口不可消失。

列表页有明确的主要滚动所有者：表格在可用高度内滚动，表头、分页和固定操作可达；设置页由配置内容区滚动。双面板可分别滚动，但不能出现同一列表两层竞争滚动；矮窗口允许改为安全的外层滚动，不以overflow:hidden剪掉内容。

页面根不得横向溢出；复杂表格和Provider列表允许内部横滚，当前/操作列固定可见。保留el-table结构、排序、勾选、分页、全屏和布局重算，不使用flex+gap手工模拟表格行。列依据实际工作区宽度和任务优先级显示/合并，低频信息始终可在详情访问，不按“必须7/8/9列”填充不存在的字段。

有选择复选框的表格，单击可选行的普通单元格切换该行勾选。复选框保留独立操作和键盘入口；链接、按钮、输入控件及选中文本不切换勾选。行点击不得绕过禁选条件；带详情的可选表格从详情入口打开，不套用无选择列的整行详情交互。

多标签主表统一用一层列表外框包住标签、表格和页脚，不在各标签内重复套框。标签使用同一高度和随选中项移动的下划线，不叠加通栏底线。媒体源、扫描任务和扫描结果的单主表不使用额外列表外框，保留表格本身的边界。

表格分页统一使用 `TablePagination`。标准分页右侧依次排列条数、每页条数与翻页控件，首末页、翻页按钮、当前页码和跳页输入均为 32px 高并居中对齐。固定页大小只展示条数，不显示下拉箭头。目录整理主表和目录覆盖在本地盘点结果稳定后使用标准数字分页，总数仅指本地已保存记录；其余状态逐页浏览，不展示末页或跳页。目录计划、广告复核和隔离历史使用标准数字分页。有外框的列表页脚与边框之间保留左右 12px 和底部 8px。

目录整理主表和目录覆盖分别支持 10、50、100 条/页，默认 100 和 50。切换条数回到第一页并重置旧游标，主表清除旧页勾选；只影响读取本地观察的页大小，不改变盘点预算。

统计区按实际指标数量自适应，窄端换行或紧凑化，不强制五等列。重命名详情面板可收起，工作区不足时使用抽屉或上下布局；关闭、确认和脏数据处理不随布局失效。登录卡最大约400px，同时受视口宽度与内边距限制。

## 5. 业务呈现

### 扫描、媒体源和任务治理

未知总量采用不定进度及已观察计数；只有接口提供可靠分母才显示百分比。耗时、最近更新、分辨率、设备、上次扫描、统计和导出逐项取自真实字段，不用轮询时间或页面行数冒充全局值。无接口的示例字段不展示，不因此增加文件探测或外部请求。

样板中的暂停、重试、批量重试不是功能授权；沿实际能力和权限显示。结果未知不能显示为可安全重试，日志已清理要单独反馈。

### 重命名

列表用于对照原名/目标名及多选，详情用于当前一条的候选和编辑。当前条目、勾选集合、当前页和全部筛选结果分别标明范围；按钮位置改变不改变动作目标或固定集合。

保留解析标题选择、TMDB/AI/多源匹配的单条/全部、预览、排除及执行语义。高低置信沿服务端状态，不混用AI confidence和元数据score。切换行、页或筛选时保护未保存编辑；迟到响应不覆盖新条目。

### 目录整理

共同入口为明确连接、目录配置和小范围子路径的本层盘点；之后并列两条工作线：目录命名建议/改名计划，以及广告人工复核/受控隔离。各自包含执行、原UUID查询、只读位置核对、明确本地提交和反向新计划。

来源名称与原不可变ID并存，历史不随当前选择漂移。legacy_unbound、授权不足、停用/归档、预算占用、未知、部分观察和已清理分别表达。完整仅表示批准范围的观察完整，不是全云盘完整；不显示不存在的递归文件数或复核完成百分比。

保护状态禁止相关写入，不禁止有权查看依据/详情/日志；最小保护入口不恢复内容权限。空状态按钮只能执行明确的本地选择或既有确认流程，不自动扫描/诊断、建Token或开放开关。

### 设置、外观和登录

保留系统设置各业务分类及直接用户权限，不添加角色；多连接、目录及授权管理与个人外观偏好分开。保存栏跟随实际滚动所有者并留底部空间，不遮挡子表/弹层；每个配置保留原CAS、保存和测试语义。

显隐只作用于当前可持有的输入，不新增取回已保存秘密的接口，不将掩码当明文保存。临时CD2 Token仅内存交接，在来源/会话变化、隐藏和关闭时清空。

登录保留当前实际记住登录、初始化、默认密码提醒/改密等能力；不展示尚未实施的失败锁定承诺。

## 6. 状态和可访问性

空、加载、无权限、失败、结果未知及观察/日志已清理分别表达；只有存在安全且有权的下一步时提供空态按钮。不能为“必须一个按钮”诱导新请求。

正常正文和必要状态文字达到4.5:1，必要控件边界、状态线索和焦点达到3:1；结构性装饰边线不机械加深。不能以contrast主题代替其他主题验收；检验正常、hover、focus、selected、readonly、disabled、error和实际复合背景。

键盘可完成选源、菜单、详情、保存和关闭；弹层返回原焦点，ESC按层级关闭，不连带退出全屏。反馈不依赖颜色，短时背景过渡约120ms并支持prefers-reduced-motion。减少无意义重复toast。

## 7. 目标变更与证据边界

本文是经用户采纳修订建议后的目标，不是截图逐像素复制合同。后续新增与修改页面统一消费本规范的语义角色和公共组件，不另起旧风格实现；实施排期见独立计划。发布、部署、运行库迁移、真实云盘操作均不由本文授权；实施差异、兼容步骤和验收结果单独记录。
