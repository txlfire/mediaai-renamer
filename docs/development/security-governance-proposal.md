# 安全治理待确认方案

类型：候选方案与实施决策准备。日期：2026-10-15。状态：待维护者确认，不是已批准设计，不代表配置或接口已实现。

## 1. 现有事实

- 安全审计audit_events没有独立自动保留/容量策略，不能套用普通运行日志的清理设置。审计意图是不同对象，已有数量20000、逻辑容量64MiB上限和未知项人工关闭流程。
- 文件日志默认30天、7天归档、总512MiB，每60秒有界维护；任务运行日志默认30天、总128MiB、单任务16MiB、每批最多1000条清理。后台普通结果默认7天、单任务4MiB、总64MiB。这些逻辑容量均不等于SQLite/WAL物理文件大小。
- admin默认密码政策是每次登录提醒，不能未经确认改成强制禁用业务；改密/重置撤销旧会话。本机应急恢复及隐藏开关已交付，登录失败限速尚未交付。
- 项目面向私人NAS及本地AI，不能直接采用“禁止所有内网地址”的SSRF策略。已有HTTPS WebDAV严格TLS、根范围/重定向/条件MOVE门禁继续生效。

依据：backend/app/core/config.py、settings_service.py、auth_service.py、audit_service.py、log_maintenance_service.py及已批准的审查政策P01～P07。不读取或复写用户实际配置。

## 2. 推荐决策

| 决策 | 推荐值与行为 | 备选及代价 |
| --- | --- | --- |
| 独立安全审计治理 | 保留365天、逻辑参考512MiB，达到80%告警；初次只观测，不自动删除。确认自动清理前先导出并核对范围 | 允许时间与容量双限自动清理会失去追溯记录，必须单独确认；长期不清理需要增加存储和归档维护 |
| 未决审计保护 | 未知文件动作、安全审计补写意图不因年龄/容量自动删除；当前硬上限和拒绝副作用机制保留 | 人工关闭必须保留原unknown、操作者与证据，不能用关闭状态伪装已成功 |
| 物理容量 | 数据库+WAL+SHM达到2GiB或数据卷空闲不足2GiB时告警；不在线自动VACUUM、不直接删除WAL | 阈值需按实际数据卷调整；全库硬停写还会影响审计/恢复，若采用应另设计保留应急空间和准确拒绝语义 |
| 登录失败限制 | 每规范化账户10分钟5次失败后冷却15分钟；来源地址另设5分钟30次上限，成功重置账户失败窗口；返回统一文案 | 账户冷却会被攻击者用来拒绝服务，内网多人共用IP会误伤；可只使用渐进延迟，需接受更多口令尝试 |
| 私人部署边界 | 保留现有NAS/本地AI可达性；可选路径根/外发主机白名单，未配置时不扩大也不额外收缩当前合法范围 | 公网部署应启用显式白名单和反向代理认证；名单变更必须使关联任务/一次性授权失效 |

表中数字是推荐候选，不是当前设置或合规要求；确认可分项，不要求一次接受全部。自动删审计、硬停写、限制私有地址及默认密码强制策略均不随“继续开发”默认生效。

## 3. 实施约束与验收准备

- 继续使用直接用户权限，不增加角色；读取治理统计复用audit:read，修改策略复用settings:write，维护动作需要明确确认及独立审计。
- 登录计数需要同数据库跨进程原子更新、有界键数量和过期清理；用户名规范化和来源哈希不能保存密码。未知账户与已知账户保持相同错误口径，不通过文案、响应体暴露账户是否存在。
- 默认只按连接实际来源计数，不信任任意X-Forwarded-For；如需可信代理名单，作为独立静态配置确认。多机部署不能把单SQLite限流当作跨机限流。
- 审计删除策略要明确未归档/补写未决项、分页中的记录消失、导出范围与保留摘要。导出成功不等于异地备份成功，禁止自动删除密钥或真实媒体。
- 物理维护只在服务及全部worker实际退出后执行，先备份相匹配的数据库、配置和密钥并检查空间。对运行库不执行VACUUM，不删除共享目录或系统临时目录。
- 预备场景：并发失败恰好一次计数、窗口边界/时钟变化、服务重启、未知账户高基数、代理伪造、冷却后恢复、改策略使旧任务失效、审计满额/磁盘满/导出失败、维护中断和旧备份恢复。尚未实现者不标成测试通过。

## 4. 只读容量核对示例

仅查询调用方明确选定的库；生产环境需先确认路径和权限。不要将以下只读核对误作清理步骤：

```sql
PRAGMA page_size;
PRAGMA page_count;
PRAGMA freelist_count;
```

项目没有ORM，继续采用sqlite3参数化SQL，不为此新增持久层。对应的可运行只读访问示例：

```python
from contextlib import closing
from pathlib import Path
import sqlite3
import sys

database = Path(sys.argv[1]).resolve(strict=True)
with closing(sqlite3.connect(database.as_uri() + "?mode=ro", uri=True)) as connection:
    pageSize = connection.execute("PRAGMA page_size").fetchone()[0]
    pageCount = connection.execute("PRAGMA page_count").fetchone()[0]
    freePages = connection.execute("PRAGMA freelist_count").fetchone()[0]
    print({"allocatedBytes": pageSize * pageCount, "freePageBytes": pageSize * freePages})
```

此值不包含WAL/SHM和文件日志，空闲页不是可直接删除的数据。未确认策略前，本轮只补决策准备，不新增清理API或数据库迁移。
