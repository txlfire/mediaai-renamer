## 协作约定

1. 每个审核主题一份交流文档，优先更新同主题文档，不为每次回复新建报告。
2. 引用原报告H/M/L或旧台账R/S/F/D/V编号，注明来源；重复发现只映射，不相加累计。
3. 结论区记录状态、代码证据、建议和限制；交流区追加日期、作者、问题及答复，不删除另一方的原始意见。
4. 状态使用成立、部分成立、不成立、待验证；源码阅读、模拟测试、实际环境证据分别标明。
5. 修复建议不是执行授权。采纳后再同步权威计划/设计；未经确认不改正式配置、不动媒体、不提交或发布。
6. 不写入账号、密码、令牌、私钥、正式数据库内容或未脱敏日志。缺少运行证据时据实保留待验证。
