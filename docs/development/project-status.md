## 4. 保留的验收与容量边界

| 项目 | 当前口径与后续动作 |
| --- | --- |
| 真实显示环境 | 常用 CSS 视口已覆盖；用户实际 3840×2160、Windows 200%＋浏览器 125%，以及笔记本 100% 仍需实机验收，不能以视口模拟替代 |
| 可访问性 | 已有键盘、焦点和有限对比度证据；读屏链、全部复合背景及 loading/active 状态未做完整 WCAG 认证 |
| NAS / NFS / WebDAV | 真实设备逐端点验收；连接和扫描成功不证明条件 MOVE 安全。不支持条件写的端点保持只读；NFS 内核阻塞须证明进程退出才能释放槽 |
| 供应商 | 合成和受控协议测试不证明每个真实 AI/元数据账号、混合路由和计费均通过；真实外发需明确授权，未知请求不重试 |
| 正式升级与回退 | 隔离库及包验证不等于用户正式实例演练；须备份数据库、配置和匹配密钥，并核对真实文件意图 |
| SQLite 容量 | 用户选择维持当前规模。6 客户端每 0.1 秒高压读取存在心跳锁争用；正常约 1.5 秒页面观察已验证，不承诺高频并发扩容 |
| 安全与物理维护政策 | 审计独立保留、数据库物理维护、登录限流、内部主机策略仍是[候选方案](security-governance-proposal.md)，不自动删除审计或在线 VACUUM |
| 工程告警 | Vite 主块超过 500kB；Actions 运行时迁移提醒继续跟踪。当前构建/CI 通过，不将警告写成已消除 |

以上不是待补交的六主题代码，也不能因正式发布而全部勾选关闭。后续先按实际环境补验；容量扩大、安全政策和新增协议另行确认范围，不自动建立新里程碑。
