## 4. 本轮验证工具核心

证据位于本机Git忽略目录`.codex/test-artifacts/cd2-c2-design-20261017/`，核心`c2_fixture_probe.py`没有创建网络连接或接收凭据的入口。它只允许三个固定测试子名及五个协议方法；生产路径、额外参数、未复核写入、无归属删除均拒绝。外层run_c2_once.py已接独占门禁、可信TLS、总预算及独立原生协议投影，另有10项离线接线测试；真实一次门禁已使用，不提供续验参数。

14项测试覆盖正常改名/改回/冲突/清理流程、方法及路径逃逸、次数/截止/间隔、未知不重试、预检替换、发送后身份变化、错误覆盖端点、非空/非本轮目录不删、只读/缺ID、发送前及发送后日志落盘失败、低层调用不能绕过复核。合成正常流为27次核心请求，实机根创建/清理、Token自检等也必须纳入总40次预算，不能在工具外隐藏消费。

这些测试证明工具保护及预期处理流程，不证明源身份原子条件，也不能校准真实115风控或误判率。原受控模式选择不等于同意无限并发或降低日志、权限、范围与不覆盖要求。
