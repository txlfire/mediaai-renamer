## 2. 最小产品范围

1. 从本人当前人工复核记录中显式选择1至5个suggest_quarantine文件，必须同父、普通文件、有固定ID和人工理由；重新核对当前观察、保留例外和保护规则，不直接使用前端路径或ID证据。
2. 目标为同父目录下既有专用隔离文件夹，名称由服务端配置，默认`_MediaAI_Quarantine`。必须在同一当前完整观察中有目录身份；产品不创建目录。不存在时先由用户在NAS建立，再按小范围重新盘点，不自动递归。
3. 保持文件名不变，只进行同云MoveFile，显式Skip、禁止跨云及递归冲突。用户不能提交任意目标路径、重命名、读取正文、删除或创建文件。
4. 目标存在同名文件时不发送移动。前后核对文件ID/大小、源父/目标父身份；不能消除外部并发替换，必须维护窗口与单写者。
5. 新增隔离计划/执行直接权限、独立默认关闭开关；C2权限不授予隔离，scan:run只可继续复核。Token精确绑定共同父根，操作只需列目录、移动及运行信息；不接受创建/写正文/删除/管理等额外权限。
6. 来源路径修订按全实例保守世代失效，不改写历史路径、不自动补扫。未知或部分执行保持全实例保护，恢复为新只读预算；反向恢复为新固定计划，不重发旧动作。

## 4. 复用与约束

- 沿用现有可信CA/HTTPS/原生gRPC、公开Token自检不附鉴权头、版本核验、进程stdin秘密交接、日志治理及本地SQLite参数绑定。不新增UI/数据库依赖或角色体系。
- 扩展全实例目录整理保护，隔离与C2、普通文件任务、扫描、同步探测、C1及匹配后台任务互斥；不能只在页面禁用按钮。
- 必须覆盖B1恢复交接、B2手动暂停优先、B3协议前保护以及新的隔离分支，不能只复制旧实现而复制缺陷。
- 每计划最多5项、30分钟；计划总量1000，单快照64KiB，最多一轮动作及五轮独立只读核对。到限停止，不删除批准/未知/审计规避容量。
- 预算等待计入截止，每次实际RPC计数且持久化发送意图，未知不因PID/超时释放。协议失败只保存固定原因码，不保存远端details/Token。
- 真实小TXT试验不扩大为大文件或所有媒体格式的验收结论。正式部署、上游复制/取样流量、实机缩放及可访问性仍按C4分别留项。

## 5. Q2实现前代码核对

- 现有`cd2_directory_protocol.py`明确不含MoveFile，CloudDriveFile投影没有文件大小字段；不能通过扩大C2方法白名单就称隔离支持。Q2使用独立最小投影，保留精确字段号、大小及目录/文件/只读/锁定等检查，不包含正文、创建或删除方法。
- 现有`Cd2DirectoryClient.findDirectory`只认可目录，`_call`也仅对RenameFile验证固定请求及解释success。Q2不能直接继承该写分支：须验证单个固定源、精确目标目录、Skip/禁止跨云/禁止递归，以及成功返回后实际位置和身份。Skip返回成功不是移动完成。
- 当前传输可复用的边界包括可信CA、HTTPS目标、关闭gRPC重试与代理、128KiB接收上限、公开GetApiTokenInfo不附鉴权头、固定版本/权限核验；关闭异常仍须finally清除内存Token，不引入主账号降级。
- 独立动作账本与RPC意图先落地，再接worker和API；每次发送须在事务中核对权限、配置、预算、等待截止与固定身份前检，不复制私有夹具工具的管理/创建/写入/清理能力。
- 扩展全实例`directoryExecutionHeld`并核对C1、C2、文件FIFO、同步探测、扫描与后台任务全部入口，未知仍占业务保护。新增Q3核对和受限手动暂停恢复时须同步所有表/查询，不仅在新页面禁用按钮。
- Q2和Q3新增表须采用后续schema迁移，不能回填为schema52已存在；Q1固定证据继续保留，不因观察清理丢失。Q3反向计划需要新的来源依据与状态分支，不能让Q1正向复核校验错误套用已失效旧观察。
