## 固定计划约束

- 最多五个明确选中的同父目录条目，保存源路径、远端 ID、原名、目标名、观察代次和规则版本；不保存 Token。
- 仅接受当前任务完整本层观察，保护季目录、光盘结构、关联素材和用户保留条目。缺少身份或目标存在时拒绝。
- 规则由服务端重算，客户端不提交远端路径或身份；请求 UUID 只用于本地幂等，不推导远端幂等。
- 缓存清理、保留变更、观察修订、策略变更使未执行计划失效。计划证据独立于观察，不随缓存删除。
- 权限按用户直接授予，不使用角色，不自动扩展已存在用户的权限。
- 不确定的大小写、Unicode 兼容名称、交换、祖孙和目标重合保持拒绝。
