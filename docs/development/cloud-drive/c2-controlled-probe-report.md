# C2 受控空目录实测报告

类型：测试报告。日期：2026-10-17。用户明确授权的一次专用空目录测试，不是正式媒体改名或C2产品交付验收。前提与场景见[详细清单](c2-acceptance-checklist.md)，过程见[阶段记录](../../work-logs/progress-2026-10-17-cd2-c2-design.md)。

## 1. 结果

当前CD2原生gRPC接口在本轮临时目录中完成同父改名、改回和同名目标冲突保护；观察到对象ID在本次改名前后保持一致。所有本轮临时目录已通过正常删除清理并核对原路径不存在，临时Token撤销且核对不存在。工具退出0，unknown=false，旧C1八个会话和25次消费未变。

这提供了受控首版的实际能力证据，**不证明服务端原子源身份条件，不保证外部客户端并发替换安全，不等于C2产品功能已实现或正式写已放行**。本轮没有WebDAV MOVE测试，不能以此补齐WebDAV条件写能力。

## 2. 环境与授权

- CD2 Core：1.1.2 Build 26-10-06 23:48:14；CLOUDAPI：1.1.2 Build 26-10-06 23:48:12。运行时重新核对，未自动升级或重启。
- 实际协议为严格证书信任的TLS/h2原生gRPC；主机、证书指纹匹配。没有跳过验证、代理切换或明文凭据兜底。
- 上传/下载/复制任务均0后开始；旧临时Token已核对不存在，原验收库schema42且无租约/worker槽。
- 在此前批准的父目录下新建唯一随机测试根，仅本轮新建的空目录；未列媒体父目录、读正文、递归或操作既有媒体。测试根建立和清理由主账号限定路径调用，其余子项由精确根短期Token执行；Token只含list/create_folder/rename/delete、600秒，无读取/写入正文、移动、永久删除或系统管理权限。
- 一次性门禁在所有真实连接之前排他预留。应用上限40次、至少2秒间隔、300秒；管理白名单上限8次另记。所有身份查找和根操作均计入应用请求，没有隐藏到管理计数。

## 3. 场景结果

| 场景 | 本次观察 |
| --- | --- |
| 唯一根及空目录 | 根建立前按随机名称核对不存在；创建后确认目录类型、路径及非空有界ID，根为空 |
| 同父改名 | source-a改为renamed-a，目标ID与原源相同，旧路径查不到 |
| 改回 | 重新核对后renamed-a改回source-a，ID相同，临时名查不到 |
| 同名冲突 | 创建独立target-b后尝试source-a改成target-b，返回拒绝；随后核对双方原ID和名称均保留 |
| 子项清理 | 每项删除前重新核对本轮ID并确认目录为空，正常删除后核对不存在 |
| 根清理 | 子项清理后重新核对根ID和为空，删除根并核对随机名称不存在 |
| 秘密与旧状态 | 临时Token撤销/不存在；旧8预算会话逐字段未变，旧控制文件未被工具覆盖 |

删除使用普通DeleteFile，不调用永久删除或清空云回收站。云端可能保留本轮空目录的回收站记录，父目录时间/缓存也可能更新；不将“原路径已清理”写成抹除所有云端历史痕迹。未为还原而再次强刷、重启或清缓存。
