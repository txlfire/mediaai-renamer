# C4 广告线索人工标注验证

文档类型：测试方案。更新：2026-10-22。离线统计工具及合成验证已完成，没有真实样本集、人工标签或实测误判率；本方案不授权列云目录、读取正文、外发AI或文件动作。

## 1. 验证对象

当前规则为`metadata-advice-v1`，使用已盘点文件名、相对路径、结构及当前条目保留信息。规则只产生`keep`或`review`；后者表示有待人工核对的线索，不是“已判定广告”，也不是删除建议。`evidenceLevel`是离散证据等级，不是概率。

人工固定复核清单中的“建议隔离/建议删除”与规则预测分开统计；不能把人工选择当成规则自身的预测结果。实际隔离还需要独立计划、权限和授权。

## 2. 样本与标签

1. 优先由操作者从已批准、本层完成且本地缓存尚在的盘点中选择一个小范围分类；不为凑样本额外递归、重读或请求新鲜数据。没有合适缓存时先确认新一次盘点范围与预算，不能复用已消费试验。
2. 样本同时包含普通媒体、字幕/海报/NFO、花絮预告、README/说明、光盘结构及疑似广告TXT/图片/视频。按当前范围选取，不要求下载内容证明标签。
3. 为每个条目分配本地匿名样本ID。私有来源映射保存任务ID、条目ID、generation、观察修订、规则版本/hash、路径水位及选取方法；公开报告只用匿名ID和分组，不复制私人路径或文件名。
4. 人工标签为`keep`、`ad`或`uncertain`，记录依据。仅凭现有元数据不能判断则保留`uncertain`，不能为了得到二分类统计强行标为广告。需要正文的样本仍待独立授权，不由本方案触发读取。
5. 先固定人工标签，再对照规则结果，减少按规则结论倒写标签。争议样本由操作者复核并保留原标签及修订理由，不静默覆盖。

预期：来源可追溯、标签与规则相互独立。常见错误：只选明显带广告词的条目、把“没有线索”标为已确认非广告、跨任务套用保留例外、观察清理后继续称为当前云状态。

## 3. 统计口径

| 人工标签 | 规则review | 规则keep |
| --- | --- | --- |
| ad | TP：广告样本被提示 | FN：广告样本未被提示 |
| keep | FP：应保留样本被提示 | TN：应保留样本未被提示 |
| uncertain | 单列，不计入混淆矩阵 | 单列，不计入混淆矩阵 |

- 提示精确率`TP/(TP+FP)`、广告召回率`TP/(TP+FN)`、保留样本误提示率`FP/(FP+TN)`，同时报告分子/分母。分母为0时记为“不适用”，不是0%或100%。
- 单独报告人工已确定数量、uncertain数量、各文件组的样本量及矩阵；受保护或人工保留条目出现review须逐项调查，不能仅用总体平均数抵消。
- 按规则输出和人工复核分别记录，不把低/中证据等级当成置信概率。元数据无法覆盖的正文广告应单列能力限制。
- 分类定向小样本只代表该样本，不外推为115全盘误判率、2PB覆盖或风控安全配额。统计阈值及扩大范围由操作者按样本代价另行决定，不在无基准时编造合格线。

## 4. 记录与停止条件

记录样本版本/选取范围、规则版本及hash、人工标签版本、混淆矩阵、争议条目、修正规则建议和证据文件哈希。报告只含脱敏数据，不导出Token、正文或可直接执行的删除命令。

来源过期、标签冲突、身份不明、例外变化或保护规则异常时停止统计或将对应项标为不可比；不自动刷新云目录来修正样本。更换规则后用冻结样本独立复验，不能删除失败样本提高指标。

本地单元/合成测试继续证明保护、预算与交互逻辑；它们不替代本方案的真实人工基准。实际结果回填[C4验收报告](c4-acceptance-report.md)，状态同步[C4清单](c4-acceptance-checklist.md)。

## 5. 离线统计工具

工具及输入格式、运行命令、退出码和常见错误见[操作说明](../../manuals/cd2-ad-label-evaluation.md)。工具只处理两个本地JSON，强制核对预先冻结的标签SHA256、相同来源快照和精确样本集合，输出总体/分组矩阵及受保护review条目；不读取运行库、不连接应用或CD2、不生成文件动作。

2026-10-22合成测试已验证四格矩阵、uncertain排除、零分母、分组、受保护条目提示、输入限制和CLI不覆盖。初轮计数缺陷由测试捕获并修正；这不是现有产品规则的误判或真实广告样本统计。工具不能验证人工标签是否独立产生或远端是否仍新鲜，报告明确保留两项未验证标志；`observationCurrent`只表示输入提供方的本地声明。
