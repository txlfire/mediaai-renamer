## 确认范围

- 只对一个显式选定目录读取本层；选择必须位于管理员配置的媒体根内。无目录发现、递归、内容读取、AI 提交或云端改名、移动、删除。
- 初始固定上限：4 次应用 RPC、批准起 30 秒、100 条接收记录、1MiB 元数据、1 个目录、深度 0。RPC 自检也计费，等待和落库也计时；不是 115 供应商配额或整分类扫描能力。
- 服务端配置固定 HTTPS 目标和可选专用 CA 文件，默认关闭网页执行。浏览器不能提交 URL、CA、主账号密码或可调预算；不自动创建、续期或撤销 CD2 Token。
- 用户自行取得精确目录、仅自检及列目录权限的短期 Token，确认后仅内存交接。现有适配器仍在第一次列目录前核对 Token 根和权限，不通过立即停止。

## 交互与接口

接口均要求应用 Bearer 会话及 `scan:run`。任务查询、启动、取消和清理均按所有者隔离，管理员不隐式绕过。

| 接口 | 契约 |
| --- | --- |
| GET /api/cloud-drive/inventory-policy | 只读本地策略：available、approvedRoot、policyHash、limits；不连接远端，不返回目标 URL、CA 路径或内容 |
| POST /api/cloud-drive/inventory-jobs | 保存确认后的任务意图，参数 requestId、selectedPath、policyHash、confirmRead=true；固定 overview 和预算，不接收 Token，不发 RPC；返回任务摘要 |
| GET /api/cloud-drive/inventory-requests/{requestId} | 按当前所有者查询该请求对应任务；未落任务返回 404，不创建或启动；用于结果未知时核对 |
| POST /api/cloud-drive/inventory-jobs/{jobId}/start | expectedRevision、policyHash、confirmRead=true、apiToken；仅 HTTPS，原子领取持久槽后交接给独立 worker，202 返回本地摘要；不等待云请求完成 |

available 只表示服务端配置及本机 CA 校验可用，不证明池已就绪、历史租约已解除、用户 Token 有效、远端可达或会话可继续；这些条件仍由启动及预算门禁逐项核对。

1. 页面先加载本地策略，用户明确选定目录，核对固定预算并填写短期 Token。
2. 用户确认后，生成一次 requestId，先可靠保存为 URL 查询参数 `inventory_request_id`，再提交不含秘密的任务意图；只有明确收到成功且任务仍 queued、范围/预算/期限符合时才启动。URL 保存失败不提交准备；准备阶段失败或结果未知时不自动进入启动。
3. 启动请求只发送一次，立即清空输入。超时、页面卸载或断线不表示远端未执行；只按原 requestId/jobId 查询，不重发启动或自动生成新 requestId。
4. 启动要求 queued、精确 revision、所有者有效、策略未变、会话未过期且池可用。持久槽领取后不能再次启动；没有 HTTP 续扫或重新排队接口。
5. 观察复用既有 1.5 秒本地摘要轮询、取消、详情、保留和清理。Token 不进入 Pinia、URL、浏览器存储、数据库、审计或日志。
6. 有未核对编号时，主入口切换为“核对原请求”；刷新页面只恢复编号，不自动查询、准备或启动。显式查询得到 queued 时，可查看原任务并在工作台取消，不提供继续启动；404不表示远端一定未执行，只有再次确认后才能移除核对标记。移除标记不撤销令牌、不取消任务，也不自动新建。
7. Token 输入为密码框；关闭、卸载、页面隐藏、离开或会话变化即清除。准备响应晚到不能交接秘密，启动响应晚到不能覆盖新页面。HTTP或策略关闭时不渲染Token表单；所有错误使用固定安全提示，不向页面传递含请求体的Axios错误对象。

示例请求体，只使用合成路径和环境变量中的应用会话。真实 Token 不写入示例文件：

```json
{
  "requestId": "df535af2-a57c-4b10-901d-c34788f0f4d9",
  "selectedPath": "/cloud/movies/欧美",
  "policyHash": "由 inventory-policy 返回的策略摘要",
  "confirmRead": true
}
```

调用顺序为读取策略 → 用户确认 → POST 任务意图 → POST start；前端启动调用只能从局部内存读取 apiToken。详细调用实现以本阶段 API 模块及测试为准，不提供含真实秘密的命令行示例。

## 安全与进程

- HTTPS 可由受控反向代理终止；部署必须限定可信代理和转发头来源，不能将任意来源的 `X-Forwarded-Proto` 当作 TLS 证明。普通 HTTP 页面不得提交 Token；后端拒绝不安全请求不代表能收回已经明文传输的秘密。
- 专用 CA 仅从管理员配置读取，有限大小并校验证书，不接受浏览器上送信任材料、不关闭证书校验。管理员固定地址是网络授权边界，不向普通用户开放任意 URL 请求能力。
- 应用生命周期仅管理主动启动的监督线程，不轮询 queued 任务，不扫描数据库寻找待重放任务。关闭时先拒绝新启动，再请求停止并等待子进程实际退出；RPC 未决租约不能随任务槽释放。
- 领取后线程/进程启动失败仍保留原任务和预算，并回收可确认退出的本机槽。数据库不可用或进程退出不确定时保持失败关闭，不能清槽后重试。
- Python/浏览器字符串不能保证物理擦除。这里只承诺不主动持久化或打印秘密，不承诺操作系统转储、恶意插件、终端注入或内存取证级别的防护。

## 数据与错误

沿用 schema42，不新增表或 ORM。SQL 仍通过 sqlite3 参数化执行；准备阶段重用 read_sessions.request_id 与 inventory_jobs.request_id，重复确认不重置计数/期限。原子领取使用 `BEGIN IMMEDIATE`，先核对所有者、状态和 revision，再写 worker 所有权。准备的两个事务间故障最多留下未绑定的批准会话，可能占用历史容量，但不会发云请求；核对或重试本地准备不能自动启动。

错误使用已有 HTTP 约定：401 未登录、403 无权限、404 非所有者/不存在、400 无效规范 UUID/路径/确认、422 类型/未知字段、409 禁用/策略变更/过期/状态或版本冲突、503 存储不可用。启动的错误结果只包含固定原因，不返回 Token、目标、证书路径或远端 details。
