## 真实产品链门禁

用户另批一次新空目录测试：原批准父目录下唯一新建空根，最多60应用RPC、20管理调用、300秒、请求至少间隔2秒。最新本地全量和浏览器通过后才消费一次性门禁；产品应用调用及夹具创建/精确查询/清理均计入，不将准备与清理藏在预算外。

正向和反向使用正常产品HTTPS API及独立worker，反向另建固定计划及新Token；重新本层观察后创建冲突目标，确认执行预检拒绝且未发送RenameFile。只核对并清理本轮拥有的空对象，不永久删除或清理云回收站；撤销Token和根清理分别核对。失败停止，不重放、不扩大路径、不重启NAS/CD2。

本轮执行完成，门禁finished；历史36应用/6管理的原生工具试验仍单列，不冒作本轮产品结果。CD2及CLOUDAPI实际构建分别为`1.1.2 Build 26-10-06 23:48:14`及`1.1.2 Build 26-10-06 23:48:12`，TLS校验及指纹核对通过，启动前上传/下载/复制均0。后端在Windows本机运行，CD2在fnOS；不是MediaAI后端在Linux/Docker的部署验收。
