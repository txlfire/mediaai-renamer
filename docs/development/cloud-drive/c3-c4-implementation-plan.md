## 2. C3-A 设计基线

- 只接收当前任务中用户明确选中的 1 至 100 个普通文件，本轮不处理目录，不扩展到整页、整个分类或后续新增观察。
- 复用本地广告线索规则；字幕、海报、光盘结构、花絮、说明文档和当前条目保留例外优先。扩展名、大小、AD 等词不能单独构成删除结论。
- 结论为保留、待确认、建议隔离、建议删除。后两者必须有明确的人工理由及规则线索，不形成任何云端执行授权。
- 服务端重新核对所属用户、任务、观察修订、完整性、路径水位和保留例外，不信任前端提交的证据或路径。
- 固定清单独立保存来源、规则版本、逐项证据、人工理由及摘要哈希。保存后不可改写；需要变更时重新选择生成新记录。
- 请求 UUID 在提交前持久化到路由，响应丢失先按原 UUID 查询，不自动重发。相同 UUID 不同内容拒绝。
- 单记录逻辑大小不超过 512 KiB，全库最多 200 条、累计逻辑大小 20 MiB，达到任一上限停止新增。不自动删除人工确认或审计；这不是数据库文件物理大小上限。
- 来源清理、修订或路径水位变化后保留历史证据，但标记不再当前；导出明确历史性质，不承诺远端身份仍有效。
- 复核权限沿用 `scan:run` 的本人本地观察维护边界，不授予取样、隔离、删除能力；后续真实动作必须新增独立权限和契约。

## 3. C3-B 安全门禁

本阶段允许查官方协议、仓库源码及本地合成验证，不新增真实云请求。真实取样、移动、删除均须另行确定目标、预算、权限及一次性授权。

内容读取须证明实际 CD2/115 流量放大和取消行为，不能将 Range 或本地截断等同上游流量上限。隔离须核对同账号同云、固定目标、不可覆盖、源身份、部分完成与恢复；C2 改名的空目录试验不能作为跨目录移动证据。

首期不开放永久删除、递归删除、自动清空隔离区或回收站，不以确认框替代缺失的原子安全能力。

## 4. 必测边界

越权、权限撤销、布尔/超限 ID、重复 ID、外部任务 ID、未完成目录、缓存清理、保留变化、路径水位变化、请求冲突、审计失败回滚、容量停止、无云 RPC；字幕/海报/正片误判；前端无默认选择、慢响应、会话切换、原 UUID 恢复、键盘和移动端；六主题浅暗、1080p、笔记本及高缩放对应 CSS 视口。
