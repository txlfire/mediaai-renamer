排期入口：[当前后续任务](../project-status.md#当前后续任务)。页面协作：[整体页面优化准备](../ui-refresh/overall-ui-preparation.md)。现有CD2范围见[多连接演进计划](../cloud-drive/multi-connection-evolution-plan.md)，本功能不增加其MC-01至37或36项计划验收场景，也不将搜索作为原多连接阶段新增发布门禁。

## 1. 原始调研事实（2026-10-25）

以下保留最初范围分析，不代表当前页面。当前入口为顶部“全局搜索”按钮和统一弹窗，不再是占位输入。

- 用户已要求开发全局搜索并加入后续任务；本次只整理排期及实施前约束，不修改产品代码。
- [App.vue](../../../frontend/src/App.vue)的顶部搜索框只有外观、placeholder和清除控件，没有搜索词绑定、输入/回车事件或检索调用。
- [M1手册](../../manuals/M1-user-manual-cn.md)记录的是占位入口；现有页面查询与媒体源下拉搜索不是全局搜索。
- [路由](../../../frontend/src/router/index.ts)已有媒体源、扫描任务、扫描结果、重命名、任务治理、目录整理和设置页面，尚无全局搜索结果路由。
- 后端使用FastAPI与SQLite，服务层使用sqlite3，不引入ORM或新搜索服务作为本任务默认前提。

## 2. 建议首版范围

以下为GS-0的推荐起点，不将尚未核对的实体、字段和读取权限写成已交付能力。

| 对象 | 推荐搜索字段与定位 | 实施前要核实的边界 |
| --- | --- | --- |
| 媒体源 | 已保存的名称、类型及允许展示的来源摘要；定位对应媒体源 | 不检索或返回连接密码、凭据字段、完整配置JSON |
| 扫描任务和已有媒体结果 | 本地任务标识、来源、文件名及解析标题；定位原任务/结果 | 只查已落库记录，不访问文件系统，不触发stat、目录遍历或重新扫描 |
| 重命名及后台任务 | 已保存的任务标识、标题和状态；定位原记录 | 各任务种类的拥有者与动作权限不同，逐项核对；不能仅有task:manage就扩大其他业务记录可见范围 |
| CD2盘点、目录计划和隔离记录 | 在多连接授权链稳定后，检索本地仍可读的观察及固定历史摘要 | 使用当前动作权限、连接授权、目录白名单和原拥有者规则；区分可清理观察与独立保留的计划/审计证据 |

首版建议不包含：媒体正文、字幕正文、图片OCR、云端在线全盘搜索、115/CD2列目录、外部AI/TMDB调用、运行日志全文及设置秘密。检索结果不提供一键改名、隔离、删除或自动恢复动作；进入原页面后仍走该页面的权限和确认链。

搜索新增与CD2本地搜索扩展可以分批交付。GS-0需明确首批实体清单，不为一次覆盖所有任务种类无限扩大范围。发布批次另定，不默认与多连接或整体UI同版发布。

## 3. 数据与安全核对清单

- [ ] 为每类对象登记实际表/字段、服务方法、读取授权、拥有者规则、目标页面与定位参数，不凭按钮权限推断读取权限。
- [ ] 普通媒体源/扫描列表目前由应用私有路由统一要求登录；后台任务已有本人规则，CD2另有来源授权。对存在差异的实体逐项确认，不静默把普通读取改成写权限，也不绕过更严格的私有记录规则。
- [ ] 查询、排名、计数和分页均以授权范围为前提；不能先全库取结果再在前端隐藏，也不能通过总数、建议或命中摘要泄露无权记录。
- [ ] 查询受理及返回前处理会话切换、撤权和迟到响应；新用户会话不能显示上一用户的结果或最近搜索。
- [ ] 输出白名单只包含定位需要的类型、稳定ID、标题、状态和允许展示的来源摘要；不返回凭据、Token、CA私钥、原始异常或配置正文。
- [ ] 导航只接受受控站内路由和稳定ID；目标已删除、观察已清理、任务归属失效或无权读取时，显示相应状态，不改写来源、不触发补扫。
- [ ] 搜索词可能含私人文件名和路径；日志默认只记长度、类型、计数、耗时和稳定错误码，不记原始查询或命中内容。首版建议不持久化最近搜索，不增加跨用户缓存。
- [ ] 输入作为SQL参数，排序/实体种类使用白名单；明确长度、空词、空白、中文、Unicode、引号、百分号和下划线的语义，不把用户输入直接拼成SQL/FTS表达式。

## 4. 容量与查询验证

全局搜索只处理本地已保存数据，2PB云容量不等于本地已有索引规模；测试记录本地行数、数据库大小、命中率和实际环境。

1. GS-0先核对现有索引、查询计划及SQLite可用能力，再比较索引前缀查询、受限子串匹配和FTS候选。不预先承诺中文全文检索、任意子串或FTS扩展一定可用。
2. 禁止按键一次请求、浏览器拉全库过滤，或把`LIKE '%词%' LIMIT n`直接当成有界读取证明。用EXPLAIN和合成大表核验实际扫描代价。
3. 推荐候选为输入防抖300ms、查询长度2至128字符、默认20条/最多50条、同一页面最多一个在途搜索；这些数值在GS-0结合中文输入法、任务ID和短标题场景确认后才冻结。
4. 旧请求可取消，并用请求代次丢弃迟到响应；页面隐藏、退出或来源条件变化后停止当前搜索，不自动重放。
5. 同类/跨类排序、游标或分页、结果上限和hasMore口径先明确。无必要不做全库COUNT；不能以不准确的“全部结果”数字掩盖截断。
6. 若需新索引或本地搜索索引，另补一致性、增删改、观察清理、授权变更、升级副本和回退验证。不得在启动时无提示索引整个云盘或迁移运行库。
7. 延迟目标、取消响应和高频限制需以测量冻结；慢查询不得拖住任务心跳、日志刷新或配置保存。沿用当前使用规模，不借搜索扩容为高频云盘请求方案。

## 6. 验收准备

- [ ] 未登录、会话失效、普通用户、管理者、无任务拥有权、仅连接授权、仅目录授权及授权撤销均有明确测试。
- [ ] 命中、无命中、部分类型失败、超时/取消、空输入、快速连续输入、中文输入法组合期间不误提交。
- [ ] 已清理的CD2观察不被当作有效盘点；固定历史仅在仍获授权时可读，不被赋予新执行资格。
- [ ] 点击结果准确定位原记录；离开和返回原页面时，不清空原筛选、选择和表单草稿，具体交互由GS-0定义。
- [ ] 验证过程中拦截并断言无文件系统扫描、CD2/115、AI/TMDB及真实媒体写调用。
- [ ] 明确本地数据规模与EXPLAIN/耗时/浏览器结果数量，不以截图或测试总数代替性能证据。
- [ ] 六主题、亮暗、键盘焦点与组合缩放复用[页面优化验收准备](../ui-refresh/overall-ui-preparation.md#4-验收环境与状态矩阵)。

第3、4、6节保留完整候选核对项，不将未选入首批的CD2历史及全矩阵自动加为本批开发门禁；当前实现、已验证与未验项以实现记录为准。
