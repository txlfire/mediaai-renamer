# 界面多语言实施计划

类型：实施规划与状态。简体中文、英语首批已接入当前开发版，包含I18N-1至I18N-3的本地验证；候选独立审核和发布另记。操作见[界面语言](../../manuals/interface-language.md)。

## 现状与边界

- `frontend/src/locales/zh-CN.ts` 为完整中文资源；英语分组由`en-US.ts`合并。类型和测试核对全部词条键及插值占位符，不通过页面重载刷新文案。已生成的消息可能保留生成时的语言。
- `interfaceLanguage.ts`负责语言白名单、偏好和响应式文案，`main.ts`将同一状态供组件、HTML语言属性和Element Plus使用。侧栏复用原控件位置，登录入口在有多个放行语言时显示，不维护第二套前端外壳。
- 仅改变界面文字、显示用日期数字、组件内置文案及可识别的用户提示。原文件名、目录、内容及媒体标题、命名规则、TMDB偏好、日志、审计、URL参数、导出内容与接口权限都不随语言变化。

## 实施批次

| 顺序 | 交付与取舍 | 可观察出口 |
| --- | --- | --- |
| I18N-1 | 已完成：基于Vue接入允许列表和浏览器偏好，登录、导航、外观、公共列表及分页使用响应式文案；Element Plus和HTML `lang`同步。 | 已有英语分组以类型和测试限定键及占位符，未迁移分组沿用中文。隔离浏览器验证实时切换、刷新持久化、表单保留和组件文案同步。 |
| I18N-2 | 已接媒体源、扫描／结果、重命名、设置、目录整理、任务、全局搜索等主要路由与提示。 | 完整词条和插值校验、七个工作区英文页面、本地无重载切换及保留草稿已验。 |
| I18N-3 | 开发版已放行登录页及侧栏选择器。英语错误按稳定状态和已知网络情况映射；数字分组只改显示。 | 刷新、登录前后、弹窗及分页组件语言同步，窄屏搜索弹窗可关闭。时间继续沿用固定格式和本地时区；读屏、实际高缩放与正式环境部署按交付待验。 |

语言偏好使用当前浏览器本地存储，只保存允许列表中的语言标识，不修改用户数据库。没有明确偏好时按浏览器语言匹配简中／英语，其它语言落到简中；存储不可用时允许本次页面切换，不阻断启动。保留返回简中的入口。

错误处理沿用现有状态码及已稳定的机器码并在显示层映射；不按中文错误句子匹配业务状态。不输出服务端原始异常或凭据，不为了翻译整体改接口契约。若关键接口缺少可用的稳定码，登记缺口并另定兼容范围。优先评估用现有 Vue 和 Element Plus 能力完成首批；若复数/语言包维护复杂度需要新依赖，先说明现有方案不足和引入影响。

验证按项目精简策略：语言/兜底/键和插值测试，受影响模块及类型检查；用同一页面实际切换后核对编辑上下文、组件语言、英文长文本和至少一个窄视口。范围外不跑真实云端，不更改数据或SQL；现场测试单列。

首批交付不包括新增语种、翻译已有数据和日志、后端接口契约统一或全站视觉重做。不改变表单初始化实际数据、路由参数、状态和权限编码。
