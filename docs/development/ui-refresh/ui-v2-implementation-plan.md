## 2. MC5首批接线

- CloudDriveSettingsPanel先区分旧source=database快照和成功的source=legacy/migrationRequired描述，再挂接多连接管理；网络/鉴权/存储错误不得触发单配置回退。
- 连接、目录和用户授权分别维护：名称、安全、生命周期使用各自修订；目录根/映射不能原地重绑；授权必须同时包含连接允许及明确目录白名单，新增目录不自动授权。
- 复用已有cloudConnections、cloudDiagnostics、cloudBoundInventory、cloudBoundActions和cloudSourceDraft；不从页面全局默认值推导原任务来源。
- 会话/权限/来源改变或关闭/隐藏时清空草稿、Token及交接票据；旧响应不能复活，旧finally不清新请求状态；未知保存先核对本地结果，未知任务查原UUID，不自动重发。
- 设置页仅配置与本地查询，保存/刷新/切换不调用CD2。页面没有迁移按钮，不借web执行离线迁移。

## 3. 视觉落地约束

样板只提供结构与视觉参考；无可靠总量时显示已观察计数与不定进度，不实现稿上任意百分比、递归文件数、预计时长、批量重试或登录锁定规则。字段与动作先列真实来源，再决定展示。

styles.css保持唯一运行时真值，保留现有变量消费接口并新增必要语义角色。个人外观继续使用本地两轴偏好；新用户forest和首屏恢复一起处理，旧合法选择不被覆盖。其他五主题完整暗色角色保留并逐态核验，不用森林色覆盖。

普通圆角6至8px、正文14px和说明13px作为起点；小字号不承载唯一关键信息。使用Element Plus图标，不强行stroke；导航中性、动作保留少量语义色。保留el-table、Provider固定列和表内横滚，不按“无滚动”剪掉内容。
