## 3. 证据格式与判定

- 每条记录测试ID、源码基线、日期、主题、模式、视口、系统/浏览器缩放、数据来源、结果和证据路径。
- 截图名称建议为`<页面>-<主题>-<模式>-<视口>-<状态>.png`，集中在本地隔离证据目录，不默认提交用户数据。
- 颜色取样使用实际computed值与实际承载背景；透明层需要按渲染背景合成，不以名义白底统一计算。
- 布局检查除横向坐标外，还检查纵向可见性与elementFromPoint/实际交互，避免“在横向范围内但被裁切”的误判。
- 切换及路由渲染等待稳定后取样，固定列使用实际DOM类名；取样为空不能直接判产品缺陷或判通过。
- 阻塞、跳过、未实测单列；部分token达标不代表全页所有复合背景、状态或无障碍合规。
- 本轮不关闭历史NAS、Linux/Docker或供应商实测开放项，也不以UI验收替代业务安全审查。
