# 后台探测与外部匹配实施计划

类型：实施与演进。日期：2026-10-14。起始develop/ea7787d及当前未提交审核、主题、桌面适配；版本1.1.0。用户授权完成可执行剩余项，测试后提交发布。

## 范围与边界

- 本阶段覆盖F02的重命名dry-run、回滚dry-run、多源元数据批量、AI批量；原同步API保留，新增后台受理与查询接口，前端使用新增入口。
- 复用isolated_task_service监督，使用独立读探测/外发执行槽，不占实际文件写FIFO。受理不探测目录、不发HTTP、不执行文件动作。
- 受理前绑定用户、请求ID、配置摘要和每项数据库快照。进程执行期间逐项、每次实际HTTP发送前及数据库发布前复核。多源线程继承执行上下文；等待计入既有外发预算。
- 未发送、运行、已知结果、中断/未知分开；进程实际退出前不释放租约，过期不重放。稳定请求ID用于查询和幂等重取，不能因HTTP超时重新创建任务。
- 存储仅保留结构化结果，丢弃服务商raw_data/提示词；执行凭据从受控本机环境/数据库读取，不写任务快照或日志。结果大小和保留期有界，清理普通结果不删除安全审计。
- SQLite迁移及参数化sqlite3沿用项目数据访问方式，项目没有ORM，不为此引入第二套持久层。
- 原审计保留/物理维护、登录限速/内网路径政策不由本阶段代用户决定。真实NAS写门禁、Docker/NFS/供应商、正式实例升级回退不能由本机回归替代。
