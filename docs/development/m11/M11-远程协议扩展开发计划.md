# M11 WebDAV 远程协议开发计划

## 1. 阶段结论

M11 的实际交付范围收敛为 HTTPS WebDAV。完成本阶段后，MediaAI Renamer 的产品功能开发进入稳定维护期。

已支持的媒体源：

- 本地路径。
- Windows UNC / SMB。
- 已挂载路径 / NFS。
- HTTPS WebDAV。

FTP、FTPS、SFTP、S3 / MinIO 仅保留为未来候选能力，不建立实施里程碑或承诺排期。

## 2. WebDAV 范围

### 2.1 已实现

- HTTPS 地址校验，不接受明文 HTTP。
- 无认证、Basic 和 Bearer 认证。
- 连接测试与 `PROPFIND Depth: 1` 目录浏览。
- 递归扫描，读取文件大小、修改时间和 ETag。
- 复用现有扫描索引、增量扫描、命名预览和命名模板。
- MOVE dry-run：校验源文件存在、目标文件不存在。
- 真实 `MOVE` 重命名，固定发送 `Overwrite: F`，禁止覆盖目标文件。
- 反向 `MOVE` 回滚。
- 数据库租约写锁、幂等远程操作明细、操作日志和审计。
- 失败恢复：安全重试、仅补齐数据库或转人工处理。
- 任务治理中的独立“WebDAV 恢复”列表、筛选、详情、分页和恢复入口。
- 独立 HTTPS WebDAV 容器环境及 GitHub Actions 真实协议测试。

### 2.2 明确不支持

- HTTP WebDAV。
- 跳过 TLS 校验或自动信任不受信任证书。
- Digest 认证。
- 覆盖已存在目标文件。
- 跨媒体源移动、跨 WebDAV 站点复制和远程目录自动挂载。
- FTP、FTPS、SFTP、S3 / MinIO 的连接、扫描或写操作。

## 3. 安全设计

- WebDAV 密码或 Token 使用媒体源版本化密文保存，API、日志和审计不回显密文。
- 所有真实写入必须经过权限校验、dry-run、用户确认、远程写锁和幂等记录。
- 同一媒体源同一时间只允许一个远程写操作。
- MOVE 使用 `Overwrite: F`，目标存在时停止，不执行覆盖。
- 扫描记录 ETag 用于增量识别；当前 MOVE 不声明通用源版本条件写能力。
- 恢复前重新检查源、目标状态；状态无法唯一判定时标记为 `recovery_required`，不自动改动远端文件。

## 5. API

```http
POST /api/media-sources/test-connection
GET  /api/media-sources/directories
GET  /api/shared-protocols/capabilities
GET  /api/remote-operations
GET  /api/remote-operations/{operation_id}
POST /api/remote-operations/{operation_id}/recover
```

媒体源保存继续使用现有新增和编辑接口。远程重命名继续复用既有
`生成预览 -> dry-run -> 确认 -> 执行` 流程，不提供绕过安全检查的写接口。
