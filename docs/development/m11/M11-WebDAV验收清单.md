# M11 WebDAV 验收清单

## 自动化验收

- [x] HTTPS Basic 连接成功。
- [x] 错误密码明确返回认证失败。
- [x] 目录浏览返回预期子目录。
- [x] 递归扫描读取文件大小和 ETag。
- [x] dry-run 拦截已存在目标。
- [x] MOVE 成功且禁止覆盖。
- [x] 反向 MOVE 可回滚。
- [x] 远端已移动时可补齐数据库。
- [x] 远端状态有歧义时转人工处理。
- [x] 有效远程写锁阻止并发恢复。
- [x] 后端全量测试通过。
- [x] 前端测试、类型检查和构建通过。
- [x] 编码检查和 `git diff --check` 通过。

## 前端人工验收

- [ ] 新增 HTTPS WebDAV 媒体源并测试连接。
- [ ] 浏览 WebDAV 目录并保存媒体源。
- [ ] 创建扫描任务并查看扫描结果。
- [ ] 生成命名预览并执行 dry-run。
- [ ] 确认后执行真实重命名。
- [ ] 创建并执行回滚计划。
- [ ] 在任务治理的“WebDAV 恢复”Tab 查看、筛选、分页和详情。
- [ ] 对可恢复记录执行恢复；对歧义状态确认系统不自动写入。
- [ ] 确认接口、页面、日志和审计中没有密码或 Token。

## 部署兼容性验收

- [ ] fnOS / NAS 运行环境信任 WebDAV 服务证书。
- [ ] 反向代理放行 `OPTIONS`、`PROPFIND`、`MOVE`、`DELETE` 等实际需要的方法。
- [ ] 反向代理保留 `Authorization`、`Depth`、`Destination` 和 `Overwrite` 请求头。
- [ ] WebDAV 账号仅拥有目标媒体目录所需的最小权限。
- [ ] 目标文件已存在时服务器拒绝覆盖。

## 不支持项

- [x] HTTP WebDAV 被拒绝。
- [x] 产品不提供跳过 TLS 校验选项。
- [x] Digest 未标记为支持。
- [x] FTP、FTPS、SFTP、S3 / MinIO 未实现。
