# fnOS 容器目录选择修复

日期：2026-07-31

## 问题

- 目录选择器固定提示“Windows 主机”，与 fnOS Docker 环境不符。
- 未指定路径时后端固定枚举 Windows 盘符，Linux 容器中返回空列表。
- “当前路径”固定使用“此电脑”作为根节点名称。
- Compose 未提供默认测试媒体目录挂载。

## 修复

- 本地目录浏览结果增加运行环境和根节点名称。
- Docker 镜像声明容器运行环境，并将默认浏览根目录设为 `/app/media`。
- Windows、Linux、macOS 和容器使用各自的提示文案及根节点名称。
- 两份 Compose 默认挂载 `./media:/app/media`。
- 提供 `media/Test/` 测试子目录，并忽略该目录下后续产生的真实媒体文件。
- fnOS 部署文档改用脱敏地址和路径示例，并补充测试目录验收步骤。

## 验证

- 后端目录浏览回归测试。
- 前端目录导航单元测试。
- 后端全量测试。
- 前端全量测试与生产构建。
- 编码检查和 Compose YAML 结构检查。
