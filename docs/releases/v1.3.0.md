# MediaAI Renamer v1.3.0

发布日期：2026-10-15。正式发布入口：[GitHub Release](https://github.com/txlfire/mediaai-renamer/releases/tag/v1.3.0)。资产和镜像状态以Release及对应CI终态为准。

## 主要变化

- 六套完整主题：清爽专业、柔和彩色、精密高对比、海盐青、林间绿、琥珀日光；每套支持亮暗，显示模式独立支持跟随系统。
- 外观改为有预览的双列单选列表，列表独立滚动，窄窗口单列、低高度使用对话框；即时保存，支持方向键、Enter/Space、ESC和焦点返回。
- 全站配色统一覆盖画布、侧栏、表格固定列、输入、按钮与浮层；预览复用同一基础值，修正浅背景状态标签的文字对比度。
- 修正说明提示拦截Enter/Space、全屏切换焦点丢失与嵌套ESC越层；截断文字及路径/超时帮助支持键盘查看。
- 命名元素支持键盘编辑、取消、重排与删除；窄窗口命名规则及操作组换行，不缩小字体或隐藏命令。
- 移除侧栏“预览版”标识，仅显示健康接口返回的实际版本；读取前仍显示“版本待确认”。

## 升级与兼容

1. 升级前备份配置、数据库及独立凭据密钥。v1.3.0沿用schema39，不新增数据库迁移或后端业务接口。
2. 使用固定版本包或`ghcr.io/txlfire/mediaai-renamer:v1.3.0`，核对健康版本1.3.0并刷新页面，确认账户、媒体源和任务状态。
3. 外观保留原存储键；旧三主题保持兼容，新主题在旧前端回退默认，不清空账户、筛选或任务数据。
4. 不删除数据库或凭据密钥来解决登录问题。从更早版本升级及回退继续遵循[v1.2.0要求](v1.2.0.md#升级要求)，旧源码不得读取不匹配schema或密文。

开发服务使用项目脚本`npm.cmd run dev:windows -- status`，仅停止时start，不用Python静态服务器或重复实例替代Vite。NAS部署见[fnOS说明](../deployment/fnos-ghcr-docker.md)。

## 验证与限制

- 六主题阶段已完成1008桌面布局、72键盘、48帮助、48浮层/固定列、22选择器、18合成长列表、十二态鼠标/边界和24编译产物场景；正式发布前复验结果另见[发布工作记录](../work-logs/progress-2026-10-15-release-1.3.0.md)。
- 发布前重新执行276项前端单测及类型/生产构建；Windows/Python3.11完整852项，840通过、12受控WebDAV跳过，无失败或错误。新发布包新装、schema20→39升级、旧备份恢复及24正式版本浏览器场景通过；远端Linux/TLS/镜像门禁以发布记录终态为准。
- 576操作颜色对及60实际状态标签取样通过；有限取样不等于所有复合背景、loading/active或WCAG认证。
- 实际4K、Windows200%与浏览器125%组合缩放、用户笔记本100%、全部读屏链仍需人工验收；常用CSS视口不能替代实机。
- 维持当前使用规模。6客户端每0.1秒高压读取存在SQLite心跳锁争用，不宣称已扩容；正常UI约1.5秒观察的边界记录保留。
- 保留v1.2.0的WebDAV严格TLS与条件MOVE门禁、未知外发不重试和审计保护。没有改变NAS配置、真实供应商账户或审计清理政策。
- Vite主块仍有500kB大小警告。本机没有Docker，镜像发布必须通过CI的测试、受控真实TLS及隔离容器健康/版本/SPA/认证/schema门禁。
