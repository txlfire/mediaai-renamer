# MediaAI Renamer v1.4.1

类型：发布说明。日期：2026-11-22。以 v1.4.0 为基础的修复版；本版不包含开发中的全局搜索、多语言或 CD2 多连接。

## 修复

- 待移动文件选中后打开移动表单时，工作台不再被内容撑出视口。
- 待移动表单和移动结果弹窗随视口收缩；长结果表在内部双向滚动，表头与关闭按钮可达。
- 超长错误信息限制首屏占用，全文仍可在错误区域滚动查看。移动确认、请求、权限和任务状态保持不变。

修复来源：`89b04a4`。该候选通过独立审核、前端全量 455 项、类型检查及 6 组隔离浏览器场景；其中 64 行合成记录验证了实际拖动滚动条，移动表单关闭不发写请求。未将合成测试作为真实媒体操作或物理缩放验收。

## 制品和升级

- [GitHub v1.4.1 Release](https://github.com/txlfire/mediaai-renamer/releases/tag/v1.4.1)：统一 ZIP `mediaai-renamer-v1.4.1.zip` 和 SHA256 校验文件。
- Docker 镜像：`ghcr.io/txlfire/mediaai-renamer:v1.4.1`。对应镜像的可用状态以标签 CI 和 Release 记录为准。
- 从 v1.4.0 升级不改数据库 schema 55，无需执行 SQL。保留原配置、数据库、凭据密钥和媒体映射；不覆盖 `config.toml`。升级与回退见 [部署说明](../deployment/fnos-ghcr-docker.md)。
- 升级后核对健康接口的版本、登录及移动表单的显示；不需要为了验证执行真实移动。若需要回退，重新部署 v1.4.0，并保持原持久化目录；仍应遵循部署文档的备份要求。
