## 主要变化

- 新增“目录整理”工作台：指定目录本层受控盘点、本地分页、目录建议、广告线索、保留例外、CSV导出与手动观察清理；不默认递归或扫描整盘。
- 新增同父目录改名固定计划、串行worker、逐项日志、原请求查询、未知保护、只读位置核对和反向新计划。
- 新增广告人工复核与同云受控隔离/反向恢复；同名冲突停止，未知结果不自动重放；不提供永久删除或媒体正文取样。
- CD2配置移至“系统设置 → 目录整理（CD2 / 115）”，保存在SQLite，不再读取旧 `[cloud_drive]` TOML段。保存只操作本地库，不自动连接或迁移旧配置，三项执行开关默认关闭。
- 补齐孤儿进程槽受限核对、本人归属及权限核对、临期计划预算、安全诊断日志，以及撤权/隐藏/会话变化和迟到响应的交接保护。
- 修复目录整理页窄屏表格高度反馈；沿用六主题浅暗风格，表格内部滚动，不以缩小字体隐藏命令。
- 源码仓库新增离线广告标签统计脚本及测试；统一运行ZIP不包含scripts工具，单独使用源码中的[工具手册](../manuals/cd2-ad-label-evaluation.md)。

## 使用与升级

1. 升级前停止新任务，处理未决请求并核对worker实际退出；备份数据库、配置和匹配的独立凭据密钥。不要用删除数据库解决登录问题。
2. v1.3.0为schema39，本版为schema55；应先在副本验证升级。回退使用旧版配套备份及镜像，不能将schema55新库直接交给旧源码。存在任务/未知保护时不要先升级。
3. 新装默认不创建admin/123456；通过登录页初始化管理员。CD2设置需用户明确维护，临时Token不持久化，网页交接必须可信HTTPS。
4. 支持的CD2与CLOUDAPI是已验证的两个精确Build组合，不是任意1.1.2/1.1.3；详见[版本表](../development/cloud-drive/cd2-runtime-compatibility.md)。
5. 改名和隔离采用维护窗口、单写者、小批量串行、前后身份核对；上游没有原子源身份条件，不能防御其他客户端并发替换。发布不等于正式媒体写入授权。
