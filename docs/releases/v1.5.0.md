# MediaAI Renamer v1.5.0

类型：发布说明。对比基线：`v1.4.1`。制品是否已公开，以 [GitHub Release](https://github.com/txlfire/mediaai-renamer/releases/tag/v1.5.0) 为准。

## 主要变化

- **目录整理**：可维护多个 CD2 连接及其媒体目录。任务明确选择来源，连接、目录和动作权限分别检查。稳定的本地盘点结果支持跳页、末页及每页 10／50／100 条，翻页不请求网盘。
- **搜索和语言**：全局搜索覆盖媒体源、扫描任务、媒体文件、重命名预览和本人有权查看的后台任务。界面支持简体中文与英语，切换不会改文件名或命名规则。
- **后台任务**：生成预览、TMDB 批量匹配和 TMDB + AI 后备可离开页面继续执行，返回后按任务编号查看。通用设置可限制后台队列活跃任务数；该限制不适用于独立扫描、实际写入及 CD2 队列。
- **服务端口**：本地开发前后端端口可在通用设置保存，下次手动重启生效；部署模式的外部端口仍由 Docker 或反向代理管理。
- **工作台**：统一多标签表格、分页和全屏；支持点击可选表格的行来切换选中。弹窗内全屏保留标题和关闭入口，Esc 先由最上层操作处理。

## 制品、升级及回退

- 发布制品为 `mediaai-renamer-v1.5.0.zip`、对应 SHA256 文件和 `ghcr.io/txlfire/mediaai-renamer:v1.5.0`，以 Release 资产与标签 CI 为准。
- SQLite 主 schema 保持 55；CD2 多连接扩展为 3，不作为应用启动的自动迁移。从旧部署保留配置、数据库一致性快照和原凭据密钥；先按[离线副本演练](../development/cloud-drive/mc6-offline-rehearsal.md)核对。回退时将旧版与恢复的原版本库配对，不让旧版直接打开扩展后的库。
- 云执行默认关闭。真实广告样本误判率仍待验证；CD2 历史搜索不在本版。发布不修改现用数据库，不自动升级 NAS 或操作媒体文件。
